TDict 便携版使用说明

====================



TDict 是一个查询 T100 ERP 数据字典的 CLI 工具，本便携版包含:

  tdict.exe      主程序 (无需安装, 解压即用)

  config.json    ERP 数据库连接配置 (需按你的环境填写)

  erp_data.db    数据字典库 (初始含表/字段字典; 校验带值/系统分类码数据需同步后才有)



第一步: 配置数据库连接

---------------------

用记事本打开 config.json, 填入可访问的 ERP 数据库连接。

当前支持 kingbase (金仓, PostgreSQL 协议)。示例:



{

  "connections": [

    { "name": "测试环境", "type": "kingbase", "host": "10.0.0.1", "port": 54321,

      "database": "topprd", "user": "dsdemo", "password": "dsdemo", "isDefault": true }

  ]

}



多个连接可并列在 connections 数组中; isDefault: true 的为默认连接。



第二步: 同步数据

----------------

打开命令行 (cmd), 进入本目录, 执行:



  tdict db sync



若 config.json 中有多个连接, 用 -c 指定连接名:



  tdict db sync -c 连接名



同步会拉取 24 张字典表 (含校验带值 5 张表 dzcd_t dzcdl_t dzce_t dzcel_t dzch_t,

系统分类码 4 张表 gzca_t gzcal_t gzcb_t gzcbl_t, 字段规格表 dzep_t,

可复用开窗 5 张表 dzca_t dzcal_t dzcb_t dzcbl_t dzcc_t),

完成后写入 erp_data.db (原库自动备份为 erp_data.db.bak)。

数据量约 50 万行, 视网络约 1~2 分钟。



第三步: 查询校验带值定义 (dzcd001)

--------------------------------

  tdict rv                列出全部校验定义

  tdict rv --kw 料号      按识别码/说明关键字过滤

  tdict rv v_ooba002_07   查看指定 dzcd001 的完整详情 (SQL/参数/判断条件)

  tdict rv v_ooba002_07 --json    JSON 输出



详情包含: 单头信息 (型态/错误讯息/行业别/说明), 校验 SQL 指令 (dzcd003 原文),

外部参数 (dzce_t, 含日期型态), 判断条件 (dzch_t)。



第四步: 查询系统分类码 (SCC)

---------------------------

系统分类码是维护各种数据/业务逻辑分类的编码, 各种下拉组件从中取值。



  tdict scc                列出全部分类码 (分类码/群组/状态/名称/值数)

  tdict scc --kw 币别      按分类码/名称关键字过滤

  tdict scc 4              查看指定 gzca001 的完整详情 (单头 + 分类值列表)

  tdict scc 4 --json       JSON 输出



详情包含: 单头 (群组 gzca004/状态 gzcastus/名称 gzcal003/说明),

分类值 (值 gzcb002/说明 gzcbl004/排序 gzcb012/标准客制 gzcb013),

扩展数据列 (gzcb003~gzcb015, 含义依各分类码而定, 如 SCC 4 存群组编号区间)。



第五步: 查询字段规格 (dzep_t)

-----------------------------

字段规格表记录数据库表所有字段的画面设计参考配置:

哪个字段用什么控件、下拉用哪个 SCC 码、格式化方式、是否必填等。



  tdict desc oobd_t             列出该表全部字段规格

  tdict desc oobd_t oobd002     查看单字段完整规格 (含 SCC 名称/取值范围/开窗/串查)

  tdict desc oobd_t --json      JSON 输出

  tdict desc oobd_t --csv       全列 CSV 输出



关键列: dzep010 控件 (03=ComboBox 05=Edit 09=RadioGroup 等),

dzep011 SCC码 (下拉/单选选项数据源, 仅 03/09 控件有效),

dzep005 必填, dzep009 显示宽度, dzep021 格式, dzep012 默认值,

dzep013/014 最大/最小值, dzep017/018 编辑/查询开窗, dzep019 校验带值。



第六步: 查询可复用开窗 (r.q)

----------------------------

可复用开窗是封装一段 SQL 的查寻窗口, 供需要开窗选取的字段复用,

设计上与校验带值同族 (设计器 adzi210 维护, adzp210 生成 q_*.4gl 开窗程序)。



  tdict rq                  列出全部开窗 (识别码/客制/说明/状态/每页笔数)

  tdict rq --kw 料号        按识别码/说明关键字过滤

  tdict rq q_apca001        查看指定 dzca001 的完整详情 (SQL/参数/显现设定)

  tdict rq q_apca001 --json JSON 输出



详情包含: 单头 (SQL 指令 dzca003 原文/每页笔数/串查编号/HardCode/行业别),

参数 (dzcb_t, 含日期型态), 显现设定 (dzcc_t: 字段/控件/是否回传构成 return1~9)。



其他命令

--------

  tdict rt dzcd_t      查询任意表的字典 (表名/字段/键值/索引)

  tdict rt dzea_t --json

  tdict -h                查看帮助



提示: 若机器上设置了 TDICT_DB 环境变量, 优先使用该路径的数据库;

可用 tdict -d erp_data.db check 显式指定本目录数据库。
