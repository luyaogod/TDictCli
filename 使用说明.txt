TDict 使用说明(便携版)
======================

一、这是什么
----------
TDict 查 T100 ERP 的数据字典与业务元数据——"系统里的这些数据是什么、怎么用":

  * 每张数据表是做什么的、每个字段的中文含义/类型/主键(表字典)
  * 字段会被怎样校验(校验规则)、校验不过显示什么错误
  * 下拉/选项从哪里来(系统分类码)、字段在画面上用什么控件(画面规格)
  * 开窗选单查什么、报错编号的文本与处理建议(系统消息)
  * 系统/单据参数的用途说明与取值范围(参数说明)

按表名或编号即可查到,输出简体中文;不用翻代码、翻画面、问人。

本包内含:
  tdict.exe      主程序(免安装,解压即用)
  erp_data.db    查询数据(约 85 万行;可 tdict db sync 从 ERP 刷新)
  config.json    环境/数据库配置(含账号等明文,请妥善保管)

二、能查什么(命令速查)
----------------------
  命令                   查什么                        例子
  tdict rt <表名>        数据表字典:表说明/字段含义/    tdict rt dzea_t
                         类型/长度/主键/键值/索引
  tdict rv [识别码]      字段校验规则(校验 SQL/参数/    tdict rv
                         条件/错误讯息)                tdict rv v_ooba002_07
  tdict scc [分类码]     系统分类码:下拉选项"值→说明"    tdict scc 4
  tdict desc <表名>      字段画面规格(控件/下拉来源/     tdict desc oobd_t
                        格式/必填/开窗)
  tdict rq [开窗码]      可复用开窗(选单查什么/回传什么)  tdict rq q_apca001
  tdict msg <编号>       系统消息:报错/提示编号的文本     tdict msg std-00006
                         与建议处理
  tdict sysp <编号>      系统参数说明(A/E/S 级参数)     tdict sysp A-SYS-0040
  tdict docp <编号>      单据参数说明(单据别+适用单据)   tdict docp D-MFG-0076
  tdict env [环境名]     查看/切换默认环境(离线)         tdict env

编号/表名长这样:表名 dzea_t、oobd_t;校验码 v_ooba002_07;分类码 4;
开窗码 q_apca001;消息编号 std-00006(负整数 SQLCODE 用 tdict msg -- -263);
参数编号 A-SYS-0040(系统级)、D-MFG-0076(单据别)。

三、数据维护
----------
查询读的是本地数据(erp_data.db)。刷新到 ERP 最新:

  tdict db sync               全量刷新(约 85 万行,视网络 2~4 分钟;需内网可达 ERP)

缺省从"默认环境"的库刷新;默认环境用 tdict env 查看/切换。
不想维护本地数据时,查询命令加 --conn <环境名> 直接查远程,例如:

  tdict msg aoo-00120 --conn 恒烁正式区

四、常用参数
----------
  --json      机器可读 JSON;--csv 平铺 CSV(列表类)
  --lang      说明语言(默认 zh_CN,可 zh_TW 等;消息/参数按语言各一条,
              没有所选语言时会列出可用语言)
  --kw        列表类命令按名称/编号过滤(如 tdict rv --kw 料号)
  --conn      直查指定环境的服务器(需网络)

查不到结果且数据看起来旧 → 先 tdict db sync;仍没有 → --conn 直查核对。

五、调试(可选)
----------
tdict debug serve 提供 T100 作业的 Web/命令行调试(需另配 SSH 环境);
本包主要为查询用途,调试用法见 tdict debug --help。
