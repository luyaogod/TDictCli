# fgl_decimal_logn()

> Returns the natural logarithm of the decimal passed as parameter.

## Syntax

```
FUNCTION fgl_decimal_logn(
   x DECIMAL )
  RETURNS DECIMAL
```

1. x is the decimal to be computed.
