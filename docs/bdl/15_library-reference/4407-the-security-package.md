# The security package

> The Genero Web Services security package provides classes and methods to support basic cryptographic features.


## Child topics

- [The RandomGenerator class](4408-the-randomgenerator-class.md): The security.RandomGenerator class includes methods for creating random strings or numbers.
- [The Base64 class](4413-the-base64-class.md): The security.Base64 class includes methods for encoding to base64 or decoding from base64.
- [The HexBinary class](4426-the-hexbinary-class.md): The security.HexBinary class includes methods for encoding to hexadecimal or decoding from hexadecimal.
- [The Digest class](4439-the-digest-class.md): The security.Digest class implements digest algorithms to process data.
- [The PBKDF2 class](4451-the-pbkdf2-class.md): The security.PBKDF2 class generates passwords using the Password-Based Key Derivation Function 2 (PBKDF2).
- [The BCrypt class](4456-the-bcrypt-class.md): The security.BCrypt class lets you save passwords as BCrypt results instead of clear text.
