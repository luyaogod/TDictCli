# BYTE data type methods

| Name | Description |
| --- | --- |
| getLength( ) RETURNS INTEGER | Returns the length of BYTE content. |
| readFile( path STRING ) | Reads a file into a `BYTE` locator. |
| writeFile( path STRING ) | Writes the content of a `BYTE` to a file. |
