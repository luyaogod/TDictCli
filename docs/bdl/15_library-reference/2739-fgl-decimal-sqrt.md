# fgl_decimal_sqrt()

> Computes the square root of the decimal passed as parameter.

## Syntax

```
FUNCTION fgl_decimal_sqrt(
   x DECIMAL )
  RETURNS DECIMAL
```

1. x is the decimal to be computed.
