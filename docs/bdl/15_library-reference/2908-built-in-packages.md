# Built-in packages

> These topics cover the built-in classes provided by the Genero Business Development Language.

> **Note:**
>
> Unlike [extension packages](3480-extension-packages.md "Several utility classes and functions are provided in additional packages."), built-in
> packages do not need to be imported with the `IMPORT` statement.

- [The ui package](3094-the-ui-package.md): These topics cover the built-in classes of the ui class
- [The om package](3280-the-om-package.md): These topics cover the built-in classes of the om package
