# File extensions

> This page describes the file extensions used by the language.

| Extension | Type | Description |
| --- | --- | --- |
| `.4gl` | Text | Source module |
| `.42m` | Binary | [Compiler p-code module](../13_programming-tools/2516-fglcomp.md "The fglcomp tool compiles .4gl source files into .42m p-code modules, and does various other tasks.") |
| `.per` | Text | [Form specification file](../11_user-interface/1662-form-specification-files.md "Form specification files are the source files defining the layout and content of application forms.") |
| `.42f` | XML | [Compiled form specification file](../13_programming-tools/2514-fglform.md "The fglform tool compiles form specification files into XML formatted files used by programs.") |
| `.42s` | Binary | [Compiled localized strings file](../13_programming-tools/2522-fglmkstr.md "The fglmkstr tool compiles .str localized string resource files.") |
| `.4st` | XML | [Presentation styles resource file](../11_user-interface/1607-presentation-styles.md "Use presentation styles to specify decoration attributes for window and form elements.") |
| `.4sm` | XML | [Startmenu resource file](../11_user-interface/2446-start-menus.md "Start menus define a tree of application programs that can be started.") |
| `.4tm` | XML | [Topmenu resource file](../11_user-interface/1866-topmenus.md "Topmenus define typical pull-down menus that appear at the top of application forms.") |
| `.4tb` | XML | [Toolbar resource file](../11_user-interface/1855-toolbars.md "Toolbars define a bar of buttons that appears at the top of application forms.") |
| `.4ad` | XML | [Action defaults resource file](../11_user-interface/1600-action-defaults-files.md "Action defaults files allow to centralize action configuration parameters such as text, icon, accelerators and behavior options in XML format.") |
| `.sch` | Text | [Database schema file - column types](../09_advanced-features/0795-column-definition-file-sch.md "The .sch database schema file contains the data types of database table columns.") |
| `.42d` | Binary (development only) | [Database schema file index (for .sch)](../09_advanced-features/0791-database-schema.md "Defines database table structures with column type information to be reused in program variable definitions.") |
| `.str` | Text | [Localized strings source file](../09_advanced-features/0901-localized-strings.md "Localized strings provide a means of writing applications in which the text of strings can be customized on site.") |
| `.val` | Text | [Database schema file - form field attributes](../09_advanced-features/0796-column-validation-file-val.md "The .val database schema file holds functional and display attributes of database table columns.") |
| `.att` | Text | [Database schema file - video attributes](../09_advanced-features/0797-column-video-attributes-file-att.md "The .att database schema file contains the default video attributes of database table columns.") |
| `.42r` | Binary | [Program file](../13_programming-tools/2537-linking-programs.md "Describes how to link .42m modules together to build a .42r program file.") |
| `.42x` | Binary | [P-code library](../13_programming-tools/2536-linking-libraries.md "Describes how to link .42m modules together to build a .42x library file.") |
| `.msg` | Text | [Message definition source file](../11_user-interface/1593-message-files.md "Message files centralize strings and larger texts identified by a number, that can be used in programs.") |
| `.iem` | Binary | [Compiled message definition file](../13_programming-tools/2518-fglmkmsg.md "The fglmkmsg tool compiles .msg message files into a binary version used by programs.") |
