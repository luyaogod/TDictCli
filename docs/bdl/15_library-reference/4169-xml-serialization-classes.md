# XML serialization classes

> The XML serialization classes convert BDL variables to XML and XML to BDL variables.


## Child topics

- [The Serializer class](4170-the-serializer-class.md): The xml.Serializer class provides methods to manage options for the serializer engine, and to use the serializer engine to serialize variables and XML element nodes.
