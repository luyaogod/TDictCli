# ui.Interface.getContainer

> Get the parent container of the current program.

> **Important:**
>
> This feature is deprecated, its use is
> discouraged although not prohibited.

## Syntax

```
ui.Interface.getContainer()
  RETURNS STRING
```

## Usage

The `ui.Interface.getContainer()` class method returns the name of the container
parent program, as defined with `ui.Interface.setContainer()`.
