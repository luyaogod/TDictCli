# base.StringTokenizer.hasMoreTokens

> Returns TRUE if there are more tokens to return.

## Syntax

```
hasMoreTokens()
  RETURNS BOOLEAN
```

## Usage

The `hasMoreTokens()` method indicates if there are other tokens in the source
string that are not yet processed.

Use the `hasMoreTokens()` method typically as the expression of a
`WHILE` block.
