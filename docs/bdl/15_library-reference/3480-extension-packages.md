# Extension packages

> Several utility classes and functions are provided in additional packages.

> **Note:**
>
> Unlike [built-in packages](2908-built-in-packages.md "These topics cover the built-in classes provided by the Genero Business Development Language."), extension
> packages must be imported with the [`IMPORT`](../09_advanced-features/0813-importing-modules.md "Use the IMPORT ... instruction to import BDL, C or Java external modules in the current module.") statement.

## Child topics

- [The util package](3481-the-util-package.md): These topics cover the classes for the util package.
- [The json package](3616-the-json-package.md): The Genero Web Services JSON package provides classes and methods to process JSON documents.
- [The os package](3696-the-os-package.md): These topics cover the classes of the os package.
- [The com package](3752-the-com-package.md): The Genero Web Services com package provides classes and methods that allow you to perform tasks associated with creating Services and Clients, and managing the services.
- [The xml package](3957-the-xml-package.md): The Genero Web Services XML package provides classes and methods to handle any kind of XML documents, including documents with namespaces.
- [The reflect package](4353-the-reflect-package.md): These topics cover the classes for the reflect package.
- [The security package](4407-the-security-package.md): The Genero Web Services security package provides classes and methods to support basic cryptographic features.
- [The prometheus package](4462-the-prometheus-package.md): These topics cover the classes for the prometheus package.
