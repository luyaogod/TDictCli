# STRING data type as class

> The STRING primitive data type provides a set of utility methods to manipulate character strings.

`STRING` methods can be invoked with a variable, for example:

```
DEFINE s STRING
IF s.equalsIgnoreCase("pink") THEN
   ...
END IF
```
