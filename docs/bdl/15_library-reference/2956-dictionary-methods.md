# DICTIONARY methods

| Name | Description |
| --- | --- |
| clear( ) | Removes all elements of the dictionary. |
| contains( key STRING ) RETURNS BOOLEAN | Checks if an element with the given key exists in the dictionary. |
| copyTo( dst dictionary-type ) | Copies all elements of the dictionary into another dictionary. |
| getKeys( ) RETURNS DYNAMIC ARRAY OF STRING | Returns a dynamic array of all keys of the dictionary. |
| getLength( ) RETURNS INTEGER | Returns the number of elements in the dictionary. |
| remove( key STRING ) | Removes an element of the dictionary identified by the key. |
