# Web services classes

> The Web services classes manage Web Services servers.

- [The WebService class](3754-the-webservice-class.md "The com.WebService class provides an interface to create and manage Genero Web Services.")
- [The WebOperation class](3770-the-weboperation-class.md "The com.WebOperation class provides an interface to create and manage the operations of a Genero Web Service.")
- [The WebServiceEngine class](3785-the-webserviceengine-class.md "The com.WebServiceEngine class provides an interface to manage the Web Services engine.")
- [The HttpServiceRequest class](3806-the-httpservicerequest-class.md "The com.HttpServiceRequest class provides an interface to process incoming XML and TEXT requests over HTTP on the server side, with an access to the HTTP layer and additional XML streaming possibilities.")
