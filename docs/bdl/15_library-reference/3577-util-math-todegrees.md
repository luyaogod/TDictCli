# util.Math.toDegrees

> Converts an angle measured in radians to an approximately equivalent angle measured in degrees.

## Syntax

```
util.Math.toDegrees(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value to be converted to degrees.
