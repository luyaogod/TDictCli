# util.Math.sqrt

> Returns the square root of the argument provided.

## Syntax

```
util.Math.sqrt(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value.

## Usage

The function returns `NULL` if the argument provided is invalid.
