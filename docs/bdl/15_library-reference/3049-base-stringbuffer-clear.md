# base.StringBuffer.clear

> Clear the string buffer.

## Syntax

```
clear()
```

## Usage

Use the `clear()` method to clear the string buffer.

After clearing, the string buffer is empty and the length is zero.

## Example

```
DEFINE buf base.StringBuffer
CALL buf.clear()
...
```
