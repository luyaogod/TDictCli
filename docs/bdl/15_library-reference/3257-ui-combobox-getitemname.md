# ui.ComboBox.getItemName

> Get an item name by position.

## Syntax

```
getItemName(
   index INTEGER )
  RETURNS STRING
```

1. index is the index of the combobox item.

## Usage

The `getItemName()` method returns the name of an item at the given position.

The first item starts at position 1.
