# ui.ComboBox.getItemText

> Get the item text by position.

## Syntax

```
getItemText(
   index INTEGER )
  RETURNS STRING
```

1. index is the index of the combobox item.

## Usage

The `getItemText()` method returns the display label of an item at the given
position.

The first item starts at position 1.
