# The ui package

> These topics cover the built-in classes of the ui class


## Child topics

- [The Interface class](3095-the-interface-class.md): The ui.Interface class provides methods to manipulate the user interface.
- [The Window class](3128-the-window-class.md): The ui.Window class provides an interface to the window objects created with the OPEN WINDOW instruction.
- [The Form class](3143-the-form-class.md): The ui.Form class provides an interface to form objects created by an OPEN WINDOW WITH FORM or DISPLAY FORM instruction.
- [The Dialog class](3169-the-dialog-class.md): The ui.Dialog class provides a set of methods to configure, query and control the current interactive instruction.
- [The ComboBox class](3247-the-combobox-class.md): The ui.ComboBox class provides an interface to the COMBOBOX form field view in the abstract user interface tree.
- [The DragDrop class](3266-the-dragdrop-class.md): The ui.DragDrop class is used to control the events related to drag & drop events.
