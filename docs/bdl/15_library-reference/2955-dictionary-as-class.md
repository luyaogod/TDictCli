# DICTIONARY as class

> The DICTIONARY type provides a set of utility methods to manipulate the dictionary elements.

`DICTIONARY` methods can be invoked with the variable, for example:

```
DEFINE d DICTIONARY OF STRING
CALL d.clear()
DISPLAY d.getLength()
```
