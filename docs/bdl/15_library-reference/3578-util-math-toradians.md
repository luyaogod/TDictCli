# util.Math.toRadians

> Converts an angle measured in degrees to an approximately equivalent angle measured in radians.

## Syntax

```
util.Math.toRadians(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value to be converted to radians.
