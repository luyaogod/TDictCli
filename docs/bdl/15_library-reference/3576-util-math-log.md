# util.Math.log

> Computes the natural logarithm of the passed value.

## Syntax

```
util.Math.log(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value.

## Usage

Returns `NULL` if the argument provided is invalid.
