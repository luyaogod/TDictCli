# Library reference

> Reference for classes and functions provided as built-in or extension packages.


## Child topics

- [Built-in functions](2724-built-in-functions.md): A built-in function is a predefined function that is part of the runtime system, or provided as a library function automatically loaded when a program starts. The built-in functions are part of the language.
- [Utility modules](2794-utility-modules.md): A utility function is a function provided in a separate library; it is not built in the runtime system.
- [Built-in packages](2908-built-in-packages.md): These topics cover the built-in classes provided by the Genero Business Development Language.
- [Built-in front calls](3385-built-in-front-calls.md): This section contains the description of all built-in front calls.
- [Extension packages](3480-extension-packages.md): Several utility classes and functions are provided in additional packages.
- [File extensions](4482-file-extensions.md): This page describes the file extensions used by the language.
- [Genero BDL errors](4483-genero-bdl-errors.md): System error messages sorted by error number.
