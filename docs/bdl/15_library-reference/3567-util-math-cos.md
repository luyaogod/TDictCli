# util.Math.cos

> Computes the cosine of the passed value, measured in radians.

## Syntax

```
util.Math.cos(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value.

## Usage

Returns `NULL` if the argument provided is invalid.
