# util.Math.exp

> Computes the base-e exponential of the value passed as parameter.

## Syntax

```
util.Math.exp(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value.

## Usage

Returns `NULL` if the argument provided on error.
