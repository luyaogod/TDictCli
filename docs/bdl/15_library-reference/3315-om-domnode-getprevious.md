# om.DomNode.getPrevious

> Returns previous sibling DOM node of this node.

## Syntax

```
getPrevious()
  RETURNS om.DomNode
```

## Usage

The `getPrevious()` method returns the previous sibling DOM node preceding the
current node, within the children list of the parent node.
