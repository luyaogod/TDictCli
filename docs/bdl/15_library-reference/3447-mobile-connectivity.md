# mobile.connectivity

> Returns the type of network available for the mobile device.

## Syntax

```
ui.Interface.frontCall("mobile", "connectivity",
   [], [result] )
```

1. result - Holds the type of network available.

## Usage

The "`mobile.connectivity`" front call is an alias for [standard.connectivity](3396-standard-connectivity.md "Returns the type of network available for the device.").
