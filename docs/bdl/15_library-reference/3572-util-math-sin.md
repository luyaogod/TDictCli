# util.Math.sin

> Computes the sine of the passed value, measured in radians.

## Syntax

```
util.Math.sin(
   x FLOAT )
  RETURNS FLOAT
```

1. x is a floating point decimal value.

## Usage

Returns `NULL` if the argument provided is invalid.
