# HTTP classes

> The HTTP classes manage HTTP client network operations on the client side.


## Child topics

- [The HttpRequest class](3847-the-httprequest-class.md): The com.HttpRequest class provides an interface to perform asynchronous XML and TEXT requests over HTTP for a specified URL, with additional XML streaming possibilities, on the client side.
- [The HttpResponse class](3888-the-httpresponse-class.md): The com.HttpResponse class provides an interface to perform XML and TEXT responses over HTTP, with additional XML streaming possibilities, on the client side.
- [The HttpPart class](3910-the-httppart-class.md): The com.HttpPart class provides an interface to manage the HTTP attachment sent or received in HTTP.
