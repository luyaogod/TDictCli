# os.Path.isDirectory

> Checks if a file is a directory.

## Syntax

```
os.Path.isDirectory(
   path STRING)
  RETURNS BOOLEAN
```

1. path is the path to the directory.

## Usage

The function returns `TRUE` if the file is a directory,
`FALSE` otherwise.
