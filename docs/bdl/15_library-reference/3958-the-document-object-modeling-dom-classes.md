# The Document Object Modeling (DOM) classes

> The Document Object Modeling (DOM) classes manage XML documents entirely in memory with support for XML Schema and DTD validation.


## Child topics

- [The DomDocument class](3959-the-domdocument-class.md): The xml.DomDocument class provides methods to manipulate a data tree, following the DOM standards.
- [The DomNode class](4020-the-domnode-class.md): The xml.DomNode class provides methods to manipulate a node of a DomDocument object.
- [The DomNodeList class](4085-the-domnodelist-class.md): The xml.DomNodeList class provides methods to manipulate a list of DomNode objects.
