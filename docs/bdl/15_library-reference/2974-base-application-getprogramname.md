# base.Application.getProgramName

> Returns the name of the current program.

## Syntax

```
base.Application.getProgramName()
  RETURNS STRING
```

## Usage

This method returns the name of the current program. This is the name of the
42m or 42r module without the file extension passed to
fglrun, .
