# os.Path.executable

> Checks if a file is executable.

## Syntax

```
os.Path.executable(
   path STRING)
  RETURNS INTEGER
```

1. path is the path to a file.

## Usage

The function returns `TRUE` if the file is executable, `FALSE`
otherwise.
