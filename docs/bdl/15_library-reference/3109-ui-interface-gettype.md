# ui.Interface.getType

> Returns the type of the program.

> **Important:**
>
> This feature is deprecated, its use is
> discouraged although not prohibited.

## Syntax

```
ui.Interface.getType()
  RETURNS STRING
```

## Usage

Use the `ui.Interface.getType()` class method to get the type of the
program previously set by `setType()`.
