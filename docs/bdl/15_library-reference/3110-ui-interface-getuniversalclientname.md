# ui.Interface.getUniversalClientName

> Returns the name of the front-end used for Universal Rendering.

> **Important:**
>
> This feature is deprecated, its use is
> discouraged although not prohibited.

## Syntax

```
ui.Interface.getUniversalClientName()
  RETURNS STRING
```

## Usage

The `ui.Interface.getUniversalClientName()` class method returns
`"GBC"`.
