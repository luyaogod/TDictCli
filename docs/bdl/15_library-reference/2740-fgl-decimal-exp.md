# fgl_decimal_exp()

> Returns the value of Euler's constant (e) raised to the power of the decimal passed as parameter.

## Syntax

```
FUNCTION fgl_decimal_exp(
   x DECIMAL )
  RETURNS DECIMAL
```

1. x is the decimal to be computed.
