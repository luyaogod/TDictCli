# The util.Channels class

> The util.Channels class provides utility functions for base.Channel objects.

This class is provided in the `util` [C-Extension](../14_extending-the-language/2703-c-extensions.md "With C-Extensions, you can bind your own C libraries in the runtime system, to call C function from the application code.") library; To use this class, import the `util` package
with:

```
IMPORT util
```

This class does not have to be instantiated; it provides class methods for
the current program.
