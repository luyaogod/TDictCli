# base.Application.getFglDir

> Returns the path to the FGLDIR installation directory.

## Syntax

```
base.Application.getFglDir()
  RETURNS STRING
```

## Usage

The `getFglDir()` method returns the installation directory path
defined by the
[FGLDIR](../07_configuration/0523-fgldir.md "Defines the installation directory of Genero Business Development Language.") environment variable.
The directory path is system-dependent.
