# ui.Interface.getImage

> Returns the icon image of the program.

## Syntax

```
ui.Interface.getImage()
  RETURNS STRING
```

## Usage

Use the `ui.Interface.getImage()` class method to get the icon image
name of the program previously set by `setImage()`.
