# ui.ComboBox.getItemCount

> Get the number of items.

## Syntax

```
getItemCount()
  RETURNS INTEGER
```

## Usage

The `getItemCount()` method returns the current number of
items defined for the `COMBOBOX` form field.

The method returns 0 (zero) if no items are defined.
