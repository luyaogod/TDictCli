# The streaming API for JSON classes

> The streaming API for JSON uses streaming to process JSON documents. These topics cover the classes for the API.


## Child topics

- [The json.JSONWriter class](3618-the-json-jsonwriter-class.md): The json.JSONWriter class provides an interface compatible with JSON streaming that writes data in a JSON format to an output source.
- [The json.JSONReader class](3639-the-json-jsonreader-class.md): The json.JSONReader class provides an interface compatible with JSON streaming that reads data in a JSON format from an input source.
- [The json.Serializer class](3662-the-json-serializer-class.md): The json.Serializer class provides methods to serialize Genero BDL variable to JSON objects and vice versa.
