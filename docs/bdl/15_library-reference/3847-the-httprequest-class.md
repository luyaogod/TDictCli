# The HttpRequest class

> The com.HttpRequest class provides an interface to perform asynchronous XML and TEXT requests over HTTP for a specified URL, with additional XML streaming possibilities, on the client side.

This class is provided in the `com` [C-Extension](../14_extending-the-language/2703-c-extensions.md "With C-Extensions, you can bind your own C libraries in the runtime system, to call C function from the application code.") library; To use this class, import the
`com` package with:

```
IMPORT com
```

The `status` variable is set to zero after a successful method call.
