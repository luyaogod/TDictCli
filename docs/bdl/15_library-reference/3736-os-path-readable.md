# os.Path.readable

> Checks if a file is readable.

## Syntax

```
os.Path.readable(
   path STRING)
  RETURNS INTEGER
```

1. path is the path to a file or directory.

## Usage

The function returns `TRUE` if the file is readable, `FALSE`
otherwise.
