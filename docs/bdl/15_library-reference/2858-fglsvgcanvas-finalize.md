# fglsvgcanvas.finalize()

> Releases the fglsvgcanvas library.

## Syntax

```
FUNCTION finalize( )
```

## Usage

This function terminates the fglsvgcanvas module usage.

It must be performed when the fglsvgcanvas library is no longer needed by the caller.
