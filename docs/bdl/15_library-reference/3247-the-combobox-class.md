# The ComboBox class

> The ui.ComboBox class provides an interface to the COMBOBOX form field view in the abstract user interface tree.

In .per form specification files, a `COMBOBOX` form field
defines both a form field and a view for that model. The `ui.ComboBox` class is an
interface to the view of a `COMBOBOX` form field. It is typically used to configure
the widget dynamically in programs, for example to create the list of items shown in the drop down
box.
