# ui.ComboBox.clear

> Clear the item list of a combobox.

## Syntax

```
clear()
```

## Usage

The `clear()` method clears the item list of the combobox.

If the item list is empty, the `COMBOBOX` drop-down button shows an
empty list on the client side.
