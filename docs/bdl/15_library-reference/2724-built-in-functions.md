# Built-in functions

> A built-in function is a predefined function that is part of the runtime system, or provided as a library function automatically loaded when a program starts. The built-in functions are part of the language.

Note that some [operators](../08_language-basics/0601-operators.md "Operators are basic syntax elements that appear in expressions.") such as
`FIELD_TOUCHED(field-spec)` look like functions,
but these are core language operators that are different in terms of semantics
and order of precedence.
