# DYNAMIC ARRAY as class

> The DYNAMIC ARRAY (or static ARRAY) type provides a set of utility methods to manipulate array elements.

`DYNAMIC ARRAY` methods can be invoked with a variable, for example:

```
DEFINE a DYNAMIC ARRAY OF STRING
CALL a.appendElement()
DISPLAY a.getLength()
```
