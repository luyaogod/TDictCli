# xml.KeyStore methods

> Methods for the xml.KeyStore class.

| Name | Description |
| --- | --- |
| xml.KeyStore.AddCertificate( global xml.CryptoX509 ) | Registers in the keystore the given X509 certificate as a certificate for the application. |
| xml.KeyStore.AddKey( global xml.CryptoX509 ) | Registers in the keystore the given key by name for the application. |
| xml.KeyStore.AddTrustedCertificate( global xml.CryptoX509 ) | Registers in the keystore the given X509 certificate as a trusted certificate for the application. |
