# Oracle Database

## Supported versions

Genero BDL supports the following Oracle Database versions:

- Oracle Database 18c, 19c, 21c and 23ai/26ai
  > **Note:**
  >
  > If you are currently using 18c, Oracle strongly recommends to ugrade to the version 19c, as a
  > long term maintenance release.
  >
  > If you are currently using 21c, Oracle strongly recommends to ugrade to the version 26ai, as a
  > long term maintenance release.
