# Dynamic SQL management

> Explains how to execute and manage SQL statements at runtime.


## Child topics

- [Understanding dynamic SQL](1141-understanding-dynamic-sql.md): This is an introduction to dynamic SQL programming.
- [PREPARE (SQL statement)](1142-prepare-sql-statement.md): Prepares an SQL statement for execution.
- [EXECUTE (SQL statement)](1143-execute-sql-statement.md): This instruction runs an SQL statement previously prepared.
- [FREE (SQL statement)](1144-free-sql-statement.md): Releases the resources allocated to a prepared statement.
- [EXECUTE IMMEDIATE](1145-execute-immediate.md): Performs a simple SQL execution without SQL parameters or result set.
- [The base.SQLHandle built-in class](1146-the-base-sqlhandle-built-in-class.md): Handle SQL queries with a 3GL API.
- [fglhint_* SQL comments](1147-fglhint-sql-comments.md): Using special SQL comment hints to control statement execution.
