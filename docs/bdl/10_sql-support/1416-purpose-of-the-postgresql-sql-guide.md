# Purpose of the PostgreSQL SQL guide

This section contains information to setup an PostgreSQL database and configure your Genero
runtime system to work with this database engine.

The guide identifies SQL incompatiblities between Informix® SQL and PostgreSQL, with the solution provided by Genero BDL.

Read carefully all pages of this section before starting your Informix to PostgreSQL migration.
