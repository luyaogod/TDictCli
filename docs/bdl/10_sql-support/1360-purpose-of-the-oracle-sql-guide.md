# Purpose of the Oracle SQL guide

This section contains information to setup an Oracle® database and configure your Genero runtime system to work with this
database engine.

The guide identifies SQL incompatiblities between Informix® SQL and Oracle SQL, with
the solution provided by Genero BDL.

Read carefully all pages of this section before starting your Informix to Oracle migration.
