# Purpose of the Informix SQL guide

This section contains information to configure your Genero runtime
system to work with an Informix® database
engine, and describes the IBM® Informix SQL features that
are not supported (or partially supported) by Genero BDL.

Understand that Genero BDL was designed to work with IBM Informix:
Most of the IBM Informix SQL features are supported. However,
new features implemented in recent server versions need modifications
in the Genero BDL compilers and runtime system to be supported.
