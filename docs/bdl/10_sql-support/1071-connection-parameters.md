# Connection parameters

> This section describes the different parameters which need to be specified in order to connect to a database.

The parameters can be provided with different methods (in the connection string or in FGLPROFILE
settings). Some of these parameters are optional.

For example, if the database user is authenticated by the operating system, username/password
parameters are not needed.
