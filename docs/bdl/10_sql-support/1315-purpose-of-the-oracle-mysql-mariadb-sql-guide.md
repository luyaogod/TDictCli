# Purpose of the Oracle MySQL / MariaDB SQL guide

This section contains information to setup an Oracle® MySQL / MariaDB database and configure your Genero runtime system to
work with this database engine.

The guide identifies SQL incompatiblities between Informix® SQL and Oracle MySQL /
MariaDB SQL, with the solution provided by Genero BDL.

Read carefully all pages of this section before starting your Informix to Oracle MySQL / MariaDB migration.
