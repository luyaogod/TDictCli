# Stored procedure calls

IBM® Informix® stored procedures are written in the SPL, C or
Java programming languages, also known as User Defined Routines.

To create a stored procedure in an IBM
Informix database, use the
`CREATE FUNCTION` statement. See reference documentation for more
details.
