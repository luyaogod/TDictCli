# SQL database guides

> This section includes the SQL guides for various supported database servers.

The SQL guides provide you with information about installation and configuration requirements,
as well as details on what is and is not supported when using database-specific SQL.

> **Note:**
>
> The SQL adaptation guides focus specific features of the target database. Read first [the General SQL programming topics](0984-sql-programming.md "Covers topics about interacting with a database server using SQL."), which cover good
> practices in database programming with Genero BDL.
