# Purpose of the Microsoft SQL Server SQL guide

This section contains information to setup a Microsoft™
SQL Server database and configure your Genero runtime system to work with this database engine.

The guide identifies SQL incompatiblities between Informix® SQL and Microsoft SQL Server Transac-SQL,
with the solution provided by Genero BDL.

Read carefullly all pages of this section before starting your Informix to Microsoft SQL
Server migration.
