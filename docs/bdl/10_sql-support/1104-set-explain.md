# SET EXPLAIN

> Turns on/off SQL report of the optimizer plan.

## Syntax

```
SET EXPLAIN { ON | OFF }
```

## Usage:

> **Important:**
>
> The `SET EXPLAIN` SQL instruction is specific to IBM® Informix®.
