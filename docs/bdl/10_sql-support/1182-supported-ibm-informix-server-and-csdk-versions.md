# Supported IBM Informix server and CSDK versions

## Supported versions

Genero BDL is certified with IBM® Informix® CSDK version **4.10** and higher.

The supported IBM Informix server types (SE, On-Line or IDS), as well as the supported server versions, are
defined by IBM Informix Client SDK compatibility specifications.

For more details, check the IBM Informix Client SDK documentation and release notes.
