# UPDATE STATISTICS

> Updates the statistics for all or for the specified table in the database.

## Syntax

```
UPDATE STATISTICS [ FOR TABLE table-specification ]
```

## Usage

> **Important:**
>
> The `UPDATE STATISTICS` SQL instruction is specific to IBM® Informix®.
