# Purpose of the SQLite SQL guide

This section contains information to setup an SQLite database and configure your Genero runtime
system to work with this database engine.

The guide identifies SQL incompatiblities between Informix® SQL and SQLite SQL, with the solution provided by Genero BDL.

Read carefully all pages of this section before starting your Informix to SQLite migration.
