# Program registers

> Predefined global registers can be used in programs to detect errors, signals and events.


## Child topics

- [status](0939-status.md): status is a predefined variable that contains the execution status of the last instruction.
- [int_flag](0940-int-flag.md): int_flag is a predefined variable set to TRUE when an interruption event is detected or when a cancel action is fired in a singular dialog.
- [quit_flag](0941-quit-flag.md): quit_flag is a predefined variable set to TRUE when a quit signal is detected.
