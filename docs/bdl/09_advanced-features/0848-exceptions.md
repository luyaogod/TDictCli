# Exceptions

> Describes exception (error) handling in the programs.


## Child topics

- [Understanding exceptions](0849-understanding-exceptions.md): Exceptions are abnormal runtime events that can be trapped for control.
- [WHENEVER directive](0850-whenever-directive.md): Use the WHENEVER directive to define how exceptions must be handled for the rest of the module.
- [TRY - CATCH block](0853-try-catch-block.md): Use TRY / CATCH blocks to trap runtime exceptions in a delimited code block.
- [Tracing exceptions](0854-tracing-exceptions.md): Exception can be logged in a file when using the STARTLOG() function.
- [Default exception handling](0855-default-exception-handling.md): Default exception handling must be adapted to your programming pattern.
- [Non-trappable errors](0856-non-trappable-errors.md): Non-trappable errors are fatal errors that generally prevent further program execution.
- [Examples](0857-examples.md): WHENEVER and TRY/CATCH usage examples.
