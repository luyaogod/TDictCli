# Localization

> Localization support allows you to implement programs that follow specific language and cultural rules.

Programs execute in a specific application locale. Beside the support of a locale
specification which defines the character set used by programs, the internationalization of an
application requires all strings in the sources that are subject to translation to be extracted and
centralized. Localized strings are used to keep application messages and form labels in external
resource files, which can be provided in different languages.

## Child topics

- [Application locale](0864-application-locale.md): The application locale defines the language and codeset for your application.
- [Localized strings](0901-localized-strings.md): Localized strings provide a means of writing applications in which the text of strings can be customized on site.
