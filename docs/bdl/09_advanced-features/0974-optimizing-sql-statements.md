# Optimizing SQL statements

SQL statement execution is often the code part of the program that
consumes a lot of processor, disk and network resources. Therefore,
it is critical to pay attention to SQL execution.

Advice for this can be found in [SQL Programming](../10_sql-support/1052-sql-performance.md "Execution time can be greatly improved, when using SQL instructions in the right way.").
