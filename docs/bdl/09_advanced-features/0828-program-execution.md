# Program execution

> This section describes program execution and language instructions related to program execution.


## Child topics

- [Executing programs](0829-executing-programs.md): There are different ways to execute compiled programs, depending on the configuration and the development or production context.
- [RUN](0830-run.md): The RUN instruction executes the command passed as argument.
- [EXIT PROGRAM](0831-exit-program.md): The EXIT PROGRAM instruction terminates the execution of the program.
- [BREAKPOINT](0832-breakpoint.md): The BREAKPOINT instruction sets a program breakpoint when running in debug mode.
