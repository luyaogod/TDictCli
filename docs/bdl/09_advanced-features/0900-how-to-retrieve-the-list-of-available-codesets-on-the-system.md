# How to retrieve the list of available codesets on the system

On UNIX™ systems, the locale -m command
gives the names of available
codesets:

```
$ locale -m
... 
ISO-8859-1 
ISO-8859-10 
ISO-8859-13 
ISO-8859-14 
ISO-8859-15
...
```
