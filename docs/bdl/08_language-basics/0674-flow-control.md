# Flow control

> Definition of language elements and instructions that control the flow of a program.


## Child topics

- [CALL](0675-call.md): The CALL instruction invokes a specified function or method.
- [RETURN](0676-return.md): The RETURN instruction gives the control of execution back to the caller, optionally returning values on the stack.
- [CASE](0677-case.md): The CASE instruction specifies statement blocks that must be executed conditionally.
- [CONTINUE block-name](0678-continue-block-name.md): The CONTINUE block-name instruction resumes execution of a loop or dialog statement.
- [EXIT block-name](0679-exit-block-name.md): The EXIT block instruction transfers control out of the current program block.
- [FOR](0680-for.md): The FOR instruction executes a statement block a specified number of times.
- [GOTO](0681-goto.md): The GOTO instruction transfers program control to a labeled line within the same program block.
- [IF](0682-if.md): The IF instruction executes a group of statements conditionally.
- [LABEL](0683-label.md): The LABEL instruction declares a jump point that can be reached by a GOTO or WHENEVER … GOTO.
- [SLEEP](0684-sleep.md): The SLEEP instruction causes the program to pause for the specified number of seconds.
- [WHILE](0685-while.md): The WHILE statement executes a block of statements until the specified condition becomes false.
