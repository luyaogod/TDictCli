# Comparison operators

> Comparison operators allow you to compare two values, to include the greater than, less than and equal to functions.

| Operator | Description |
| --- | --- |
| [IS NULL](0606-is-null.md "The IS NULL operator checks for NULL values.") | The `IS NULL` operator checks for `NULL` values. |
| [LIKE](0607-like.md "The LIKE operator returns TRUE if a string matches a given mask.") | The `LIKE` operator returns `TRUE` if a string matches a given mask. |
| [MATCHES](0608-matches.md "The MATCHES operator returns TRUE if a string matches a given mask.") | The `MATCHES` operator returns `TRUE` if a string matches a given mask. |
| [Equal to (== or =)](0609-equal-to-or.md "The == operator checks for equality of two expressions or for two record variables. A single = can be used as alias for ==.") | The `==` operator checks for equality of two expressions or for two record variables. A single `=` can be used as alias for `==`. |
| [Different from (!= or <>)](0610-different-from-or.md "The != operator checks for non-equality of two expressions or for two record variables. The <> can be used as alias for !=.") | The `!=` operator checks for non-equality of two expressions or for two record variables. The `<>` can be used as alias for `!=`. |
| [Lower (<)](0611-lower.md "The < operator is provided to test whether a value or expression is lower than another.") | The `<` operator is provided to test whether a value or expression is lower than another. |
| [Lower or equal (<=)](0612-lower-or-equal.md "The <= operator is provided to test whether a value or expression is lower than or equal to another.") | The `<=` operator is provided to test whether a value or expression is lower than or equal to another. |
| [Greater (>)](0613-greater.md "The > operator is provided to test whether a value or expression is greater than another.") | The `>` operator is provided to test whether a value or expression is greater than another. |
| [Greater or equal (>=)](0614-greater-or-equal.md "The >= operator is provided to test whether a value or expression is greater than or equal to another.") | The `>=` operator is provided to test whether a value or expression is greater than or equal to another. |
| [NVL() [function]](0615-nvl-function.md "The NVL() operator returns the second parameter if the first argument evaluates to NULL.") | The `NVL()` operator returns the second parameter if the first argument evaluates to `NULL`. |
| [IIF() [function]](0616-iif-function.md "The IIF() returns the second or third parameter depending on the boolean expression given as first argument.") | The `IIF()` returns the second or third parameter depending on the boolean expression given as first argument. |
| [IN()](0617-in.md "The IN() operator compares an expression to a list of values.") | The `IN()` operator compares an expression to a list of values. |
