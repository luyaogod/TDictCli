# Assignment operators

> An assignment operator allows you to assign a variable with an expression.

| Operator | Description |
| --- | --- |
| [Assignment (:=)](0651-assignment.md "The := operator assigns a variable with an expression and returns the result.") | The `:=` operator assigns a variable with an expression and returns the result. |
| [Addition Assignment (+=) [LET]](0652-addition-assignment-let.md "The += operator used after the LET keyword, assigns a variable by adding the current variable value to a numeric expression.") | The `+=` operator used after the `LET` keyword, assigns a variable by adding the current variable value to a numeric expression. |
| [Subtraction Assignment (-=) [LET]](0653-subtraction-assignment-let.md "The -= operator used after the LET keyword, assigns a variable by subtracting the current variable value to a numeric expression.") | The `-=` operator used after the `LET` keyword, assigns a variable by subtracting the current variable value to a numeric expression. |
| [Multiplication Assignment (\*=) [LET]](0654-multiplication-assignment-let.md "The *= operator used after the LET keyword, assigns a variable by multiplying the current variable value to a numeric expression.") | The `*=` operator used after the `LET` keyword, assigns a variable by multiplying the current variable value to a numeric expression. |
| [Division Assignment (/=) [LET]](0655-division-assignment-let.md "The /= operator used after the LET keyword, assigns a variable by dividing the current variable value by a numeric expression.") | The `/=` operator used after the `LET` keyword, assigns a variable by dividing the current variable value by a numeric expression. |
| [Concatenation Assignment (\|\|=) [LET]](0656-concatenation-assignment-let.md "The \|\|= operator used after the LET keyword, assigns a variable by concatenating the current variable value to an expression.") | The `\|\|=` operator used after the `LET` keyword, assigns a variable by concatenating the current variable value to an expression. |
| [Append Assignment (,=) [LET]](0657-append-assignment-let.md "The ,= operator used after the LET keyword, assigns a variable by concatenating the current variable value with the formatted version of an expression.") | The `,=` operator used after the `LET` keyword, assigns a variable by concatenating the current variable value with the formatted version of an expression. |
