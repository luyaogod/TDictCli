# Syntax features

> Genero BDL is an English-like programming language, easy to write and read.


## Child topics

- [Lettercase insensitivity](0545-lettercase-insensitivity.md): Genero BDL is case insensitive (with some exceptions).
- [Whitespace separators](0546-whitespace-separators.md): Whitespace characters are used to separate language elements.
- [String delimiters](0547-string-delimiters.md): String literals need to be delimited by specific characters.
- [Escape symbol](0548-escape-symbol.md): Backslash ( \ ) is the escape character of Genero BDL.
- [Statement terminator](0549-statement-terminator.md): The semicolon ( ; ) is optional statement terminator in Genero BDL.
- [Source comments](0550-source-comments.md): The --, # and { } characters can be used to add source comments.
- [Identifiers](0551-identifiers.md): A Genero BDL identifier is a sequence of characters used to identify a program entity.
- [Preprocessor directives](0552-preprocessor-directives.md): Preprocessor directives can be used in Genero BDL sources.
