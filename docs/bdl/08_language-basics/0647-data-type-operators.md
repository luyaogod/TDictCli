# Data type operators

> Data type operators allow you cast a data type or create an instance of a data type.

| Operator | Description |
| --- | --- |
| [CAST() [function]](0648-cast-function.md "The CAST operator converts a Java object to the user-defined type or Java class specified.") | The `CAST` operator converts a Java object to the user-defined type or Java class specified. |
| [INSTANCEOF](0649-instanceof.md "The INSTANCEOF checks the class of an object.") | The `INSTANCEOF` checks the class of an object. |
