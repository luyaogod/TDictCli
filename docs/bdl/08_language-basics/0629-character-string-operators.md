# Character string operators

> Character string operators allow you to work with and manipulate character strings.

| Operator | Description |
| --- | --- |

| [COLUMN](0631-column.md "The COLUMN operator generates blanks.") | The `COLUMN` operator generates blanks. |
| [Concatenate (\|\|)](0632-concatenate.md "The \|\| operator makes a string concatenation.") | The `\|\|` operator makes a string concatenation. |
| [Substring ([s,e])](0633-substring-s-e.md "The [] (square brackets) operator extracts a substring from a variable.") | The `[]` (square brackets) operator extracts a substring from a variable. |
| [USING](0634-using.md "The USING operator converts date and numeric values to a string based on a formatting mask.") | The `USING` operator converts date and numeric values to a string based on a formatting mask. |
| [CLIPPED](0635-clipped.md "The CLIPPED operator removes trailing blank spaces (ASCII 32) of a string expression.") | The `CLIPPED` operator removes trailing blank spaces (ASCII 32) of a string expression. |
| [ORD() [function]](0636-ord-function.md "The ORD() operator returns the code point of a character in the current locale.") | The `ORD()` operator returns the code point of a character in the current locale. |
| [SPACES](0637-spaces.md "The SPACES operator returns a character string with blanks.") | The `SPACES` operator returns a character string with blanks. |
| [LSTR() [function]](0638-lstr-function.md "The LSTR() operator returns a localized string.") | The `LSTR()` operator returns a localized string. |
