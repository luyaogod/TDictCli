# Multiplication (*)

> The * operator multiplies a number with another.

## Syntax

```
num-expr * num-expr
```

1. num-expr is a numeric expression.

## Usage

Use the `*` operator
to multiply a numeric value to another numeric value.

If one of the operands is `NULL`, the arithmetic expression evaluates to
`NULL`.

## Example

```
MAIN
  DISPLAY 100 * 200
END MAIN
```
