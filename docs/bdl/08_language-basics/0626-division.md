# Division (/)

> The / operator divides a number by another.

## Syntax

```
num-expr / num-expr
```

1. num-expr is a numeric expression.

## Usage

Use the `/` operator
to divide a numeric value by another numeric value.

If one of the operands is `NULL`, the arithmetic expression evaluates to
`NULL`.

## Example

```
MAIN
  DISPLAY 100 / 200
END MAIN
```
