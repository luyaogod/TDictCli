# Arithmetic operators

> Arithmetic operators allow you to complete numeric operations, such as addition and subtraction.

| Operator | Description |
| --- | --- |
| [Addition (+)](0623-addition.md "The + operator adds a number to another.") | The `+` operator adds a number to another. |
| [Subtraction (-)](0624-subtraction.md "The - operator subtracts a number from another.") | The `-` operator subtracts a number from another. |
| [Multiplication (\*)](0625-multiplication.md "The * operator multiplies a number with another.") | The `*` operator multiplies a number with another. |
| [Division (/)](0626-division.md "The / operator divides a number by another.") | The `/` operator divides a number by another. |
| [Exponentiation (\*\*)](0627-exponentiation.md "The ** operator calculates an exponentiation.") | The `**` operator calculates an exponentiation. |
| [MOD](0628-mod.md "The MOD operator calculates the modulus.") | The `MOD` operator calculates the modulus. |
