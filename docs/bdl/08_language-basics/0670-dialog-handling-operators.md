# Dialog handling operators

> Dialog handling operators allow you to handle variables in a DIALOG statement.

| Operator | Description |
| --- | --- |
| [GET\_FLDBUF() [function]](0671-get-fldbuf-function.md "The GET_FLDBUF() operator returns as character strings the current values of the specified fields.") | The `GET_FLDBUF()` operator returns as character strings the current values of the specified fields. |
| [INFIELD() [function]](0672-infield-function.md "The INFIELD() operator checks for the current screen field.") | The `INFIELD()` operator checks for the current screen field. |
| [FIELD\_TOUCHED() [function]](0673-field-touched-function.md "The FIELD_TOUCHED() operator checks if fields were modified during the dialog execution.") | The `FIELD_TOUCHED()` operator checks if fields were modified during the dialog execution. |
