# Primitive Data types

> Selecting the correct data type assists you in the input, storage, and display of your data.

## Child topics

- [BIGINT](0554-bigint.md): The BIGINT data type is used for storing very large whole numbers.
- [BYTE](0555-byte.md): The BYTE data type stores any type of binary data, such as images or sounds.
- [BOOLEAN](0556-boolean.md): The BOOLEAN data type stores a logical value, TRUE or FALSE.
- [CHAR(size)](0557-char-size.md): The CHAR data type is a fixed-length character string data type.
- [DATE](0558-date.md): The DATE data type stores calendar dates with a Year/Month/Day representation.
- [DATETIME qual1 TO qual2](0559-datetime-qual1-to-qual2.md): The DATETIME data type stores date and time data with time units from the year to fractions of a second.
- [DECIMAL(p,s)](0560-decimal-p-s.md): The DECIMAL data type is provided to handle large numeric values with exact decimal storage.
- [FLOAT](0561-float.md): The FLOAT data type stores values as double-precision floating-point binary numbers with up to 16 significant digits.
- [INTEGER](0562-integer.md): The INTEGER data type is used for storing large whole numbers.
- [INTERVAL qual1 TO qual2](0563-interval-qual1-to-qual2.md): The INTERVAL data type stores spans of time as Year/Month or Day/Hour/Minute/Second/Fraction units.
- [MONEY(p,s)](0564-money-p-s.md): The MONEY data type is provided to store currency amounts with exact decimal storage.
- [SMALLFLOAT](0565-smallfloat.md): The SMALLFLOAT data type stores values as single-precision floating-point binary numbers with up to 8 significant digits.
- [SMALLINT](0566-smallint.md): The SMALLINT data type is used for storing small whole numbers.
- [STRING](0567-string.md): The STRING data type is a variable-length, dynamically allocated character string data type, without limitation.
- [TINYINT](0568-tinyint.md): The TINYINT data type is used for storing very small whole numbers.
- [TEXT](0569-text.md): The TEXT data type stores large text data.
- [VARCHAR(size)](0570-varchar-size.md): The VARCHAR data type is a variable-length character string data type, with a maximum size.
