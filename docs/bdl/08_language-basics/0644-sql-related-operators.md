# SQL related operators

> SQL related operators allow you to retrieve the SQL state and the SQL error message.

| Operator | Description |
| --- | --- |
| [SQLSTATE [variable]](0645-sqlstate-variable.md "The SQLSTATE predefined variable returns the code corresponding to the last SQL error.") | The `SQLSTATE` predefined variable returns the code corresponding to the last SQL error. |
| [SQLERRMESSAGE [variable]](0646-sqlerrmessage-variable.md "The SQLERRMESSAGE predefined variable holds the error message corresponding to the last SQL error.") | The `SQLERRMESSAGE` predefined variable holds the error message corresponding to the last SQL error. |
