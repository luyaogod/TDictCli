# Dictionary methods

> Dictionary variables can be used to invoke built-in methods.

For example, to clear a dictionary, use the `clear()`
method:

```
DEFINE dict DICTIONARY OF ...
CALL dict.clear()
```

For the list of dictionary methods, see [DICTIONARY methods](../15_library-reference/2956-dictionary-methods.md).
