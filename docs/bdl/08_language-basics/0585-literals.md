# Literals

> Describes the syntax of literals (constant values) to be used in sources.


## Child topics

- [Integer literals](0586-integer-literals.md): Integer literals define a whole number in an expression.
- [Numeric literals](0587-numeric-literals.md): Numeric literals define values with a decimal part in an expression.
- [Text literals](0588-text-literals.md): Text literals define a character string in an expression.
- [MDY(m,d,y) literals](0589-mdy-m-d-y-literals.md): MDY() literals define a DATE literal in an expression.
- [Datetime literals](0590-datetime-literals.md): Datetime literals define date/time value in an expression.
- [Interval literals](0591-interval-literals.md): Interval literals define an interval value in an expression.
