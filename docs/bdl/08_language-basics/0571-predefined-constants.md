# Predefined constants

> The language defines a set of global constants that can be used in the programs.


## Child topics

- [NULL](0572-null.md): The NULL constant defines a non-value.
- [TRUE](0573-true.md): TRUE is a predefined constant to be used in boolean expressions.
- [FALSE](0574-false.md): FALSE is a predefined constant to be used in boolean expressions.
- [NOTFOUND](0575-notfound.md): NOTFOUND is a predefined constant used to check if an SQL statement returns rows.
