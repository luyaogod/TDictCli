# DBEDIT

> Defines the editor program for TEXT fields in TUI mode.

The DBEDIT environment variable defines the editor program to modify the values of form fields
defined with the [`TEXT`](../08_language-basics/0569-text.md "The TEXT data type stores large text data.") data type, when
running programs on dumb terminals.
