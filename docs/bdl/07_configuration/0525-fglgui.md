# FGLGUI

> Defines the user interface mode to be used by the program.

The FGLGUI environment variable indicates whether the applications are run in TUI or GUI mode.

| FGLGUI | Description |
| --- | --- |
| 0 (zero) | The application executes in TUI (text) mode. |
| 1 (default) | The application executes in GUI (graphical) mode and needs a front-end to display application windows. |
