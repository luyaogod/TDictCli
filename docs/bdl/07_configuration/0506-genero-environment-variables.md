# Genero environment variables

This section lists and describes in detail all Genero specific environment variables.

## Child topics

- [DBCENTURY](0507-dbcentury.md): Specifies the expansion for the century in DATE and DATETIME values.
- [DBDATE](0508-dbdate.md): Defines the default display and input format for DATE values.
- [DBDELIMITER](0509-dbdelimiter.md): Defines the value separator for unload data files.
- [DBEDIT](0510-dbedit.md): Defines the editor program for TEXT fields in TUI mode.
- [DBFORMAT](0511-dbformat.md): Defines the characters to be used for the currency symbol, decimal and thousands separators for numeric values.
- [DBMONEY](0512-dbmoney.md): Defines the characters to be used for the currency symbol and decimal separator for numeric values, when DBFORMAT is not defined.
- [DBPATH](0513-dbpath.md): Defines a list of paths for Genero program resource files.
- [DBPRINT](0514-dbprint.md): Defines the print device to be used by reports.
- [DBSCREENDUMP](0515-dbscreendump.md): Defines the output filename for text screen shots.
- [DBSCREENOUT](0516-dbscreenout.md): Defines the output filename for text screen shots.
- [DBTEMP](0517-dbtemp.md): Defines the directory for temporary files.
- [FGL_LENGTH_SEMANTICS](0518-fgl-length-semantics.md): Defines the length semantics to be used in programs.
- [FGLAPPDIR](0519-fglappdir.md): Contains the path to the application directory when executing on a mobile device.
- [FGLAPPSERVER](0520-fglappserver.md): Defines the listening TCP port of the Web service in development context.
- [FGLCOV](0521-fglcov.md): Enables code coverage data collection.
- [FGLDBPATH](0522-fgldbpath.md): Defines a list of paths to database schema files for compilers.
- [FGLDIR](0523-fgldir.md): Defines the installation directory of Genero Business Development Language.
- [FGLGBCDIR](0524-fglgbcdir.md): Defines the GBC component to be used in GUI direct mode.
- [FGLGUI](0525-fglgui.md): Defines the user interface mode to be used by the program.
- [FGLGUIDEBUG](0526-fglguidebug.md): Defines the debug level in GUI mode.
- [FGLIMAGEPATH](0527-fglimagepath.md): Defines a list of paths and filenames for image resources.
- [FGLLDPATH](0528-fglldpath.md): Defines a list of paths to find program modules.
- [FGLLICENSE](0529-fgllicense.md): The FGLLICENSE environment variable identifies the configuration file (or files) for the fglWrt license controller.
- [FGLPROFILE](0530-fglprofile.md): Defines the configuration files to be used by the runtime system.
- [FGLRESOURCEPATH](0531-fglresourcepath.md): Defines a list of paths for program resource files.
- [FGLSERVER](0532-fglserver.md): Defines the graphical front-end for the application.
- [FGLSOURCEPATH](0533-fglsourcepath.md): Defines a list of paths to program source files.
- [FGLSQLDEBUG](0534-fglsqldebug.md): Defines the debug level for tracing SQL instructions.
- [FGLTRACE_FUNCTIONS](0535-fgltrace-functions.md): Defines the list of functions to be followed by the program execution trace.
- [FGLTRACE_EXCLUDE](0536-fgltrace-exclude.md): Defines the list of functions to be excluded from the program execution trace.
- [FGLWSDEBUG](0537-fglwsdebug.md): The FGLWSDEBUG environment variable enables web services library debugging.
- [GMIDIR](0538-gmidir.md): Defines the installation directory of Genero Mobile for iOS.
- [INFORMIXTERM](0539-informixterm.md): Defines terminal control library to be used.
- [VSCODE_FGLDA_IPCPATH](0540-vscode-fglda-ipcpath.md): Defines the communication channel for the FGL debugger in VS Code.
