# FGLLICENSE

> The FGLLICENSE environment variable identifies the configuration file (or files) for the fglWrt license controller.

By default, the configuration file is $FGLDIR/etc/fgllicense.

When listing multiple license configuration files, the filenames must be separated by the
operating system-specific path separator. The path separator is **":"** on UNIX™ platforms and **";"** on Windows® platforms.

For more details about license installation and configuration, see the Install and License your Genero Products and Four Js License Manager User Guide.
