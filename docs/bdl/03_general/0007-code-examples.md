# Code examples

> Code examples contain code that can be copied as-is.

Code examples appear in the documentation as follows:

```
MAIN
  DEFINE a1 ARRAY[100] OF INTEGER,
         a2 ARRAY[10,20] OF RECORD
         id INTEGER,
...
```
