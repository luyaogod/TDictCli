# XML support

> The language provides XML support through different classes, depending on your needs.

Genero XML support is provided in two forms:

- For basic XML tasks related to the user interface, use the [built-in XML classes](../09_advanced-features/0948-xml-support.md "Introduces to DOM and SAX standards and describes the XML utility classes built-in the language.").
- For complex XML tasks, and Web Services functions, use the full-featured XML
  classes provided in the [web services extension](../16_web-services/4484-web-services.md "Create a web service client or server with Genero BDL.").
