# gwa.app.TBuildDateTime type

> The TBuildDateTime type defines a record for the build date time stamp.

## Syntax

```
TYPE TBuildDateTime DATETIME YEAR TO FRACTION
```

## Usage

It provides a type for getting a build date time stamp. A variable of the type
`TBuildDateTime` must be defined.
