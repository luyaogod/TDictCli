# IPv6 support with Genero

> Network interface configuration for IPv6 support

## IPv6 basics

IPv6 is the successor for IPv4, to increase the possible number of nodes of a computer network.

## IPv6 support for WS clients

A Web Services client program can by default access a WS server using IPv6. For more details, see
[Configure a WS client to use IPv6](../16_web-services/4635-configure-a-ws-client-to-use-ipv6.md "Configuration steps to customize IPv6 for a WS client.").

Web Services server programs work only in IPv4 to communicate with the GAS (since there is no
need for IPv6 on a localhost). It's up to the Web server to support IPv6 for the internet access of
WS clients.
