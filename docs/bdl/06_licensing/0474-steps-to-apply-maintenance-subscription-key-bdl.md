# Steps to apply maintenance/subscription key (BDL)

> You apply a maintenance/subscription key when you are installing a license for a product and thereafter when you renew your maintenance contract or your subscription license.

An active
maintenance contract and a maintenance key is required to license or renew a product licensed with a
perpetual license. A subscription key is required to license or renew a license for a product with a
subscription license. Use this procedure to apply the maintenance/subscription key regardless of
which license type you have.

Before you begin applying a maintenance/subscription key:

1. Decide which tool (GUI or command line) you are using to install the key:
   - Genero BDL Licenser (GUI application)
   - fglWrt (command line tool).
2. Determine if you have internet access from the machine you are licensing the product.
3. Use Table 1 to choose
   your licensing option, and select the procedure to follow.

| You are using ... | Procedure to follow |
| --- | --- |
| Genero BDL Licenser with internet | See [Install or update BDL maintenance/subscription key using GUI and internet](0475-apply-maintenance-subscription-key-using-gui-internet.md "Use the Genero licensing graphical interface to install or update your maintenance/subscription key."). |
| Genero BDL Licenser without internet. | See [Install or update BDL maintenance/subscription key using GUI without internet](0476-apply-maintenance-subscription-key-using-gui-no-internet.md "Without internet access, you register the license with Four Js from another machine via the internet, or by phone. Then use the Genero licensing graphical interface to install or update the maintenance/subscription key of your product."). |
| fglWrt command line tool with internet. | See [Install or update BDL maintenance/subscription key from the command line (via internet)](0477-apply-maintenance-subscription-key-with-fglwrt-internet.md "You can install or update the maintenance/subscription key of your BDL product using the command fglWrt -m auto."). |
| fglWrt command line tool without internet. | See [Install or update BDL maintenance/subscription key from the command line (no internet)](0478-apply-maintenance-subscription-key-with-fglwrt-no-internet.md "Without internet access, you register the license with Four Js from another machine via the internet, or by phone. Then use the fglWrt command line tool to install or update the maintenance/subscription key of your product."). |
