# Uninstall license with BDL Licenser

> Use the Genero licensing graphical interface to uninstall your Genero BDL product license.

**About this task:**

> **Note:**
>
> This procedure is valid for a local license only. If you are using the Four Js License Manager,
> see Manage licenses with FLM in Four Js License Manager User Guide.

1. Launch the Genero licensing user interface.
   - From Genero Studio, select Tools > Genero Tools > Genero BDL Licenser.
   - From the Window Start menu, select the Genero BDL
     Licenser tool from your Four Js program list.

   The licensing page opens in a Web browser.
2. Click Uninstall license.

   The description field is updated to show a license is not
   installed.
3. Click Quit Licensing to close the licensing application.
