# Get the maintenance/subscription key

> You get the maintenance/subscription key from the Four Js website to ensure you have a valid key to install or update your product's license.

**Before you begin:**

You must also have the following:

- Customer code
- License number

**About this task:**

If you can use the option to install the maintenance/subscription key via the internet (`fglWrt -m auto` or `greWrt -m
auto`), then you do
not need to perform this task.

1. Open your browser and navigate to the [Four Js](https://4js.com/) website.
2. Navigate to the Support  >  License your products  page.
3. Scroll to the Online maintenance section.

   Use this form to get the maintenance/subscription key regardless of which license type you have.

   ![The image shows the Online maintenance form on the License your products page on the Four Js web site at https://4js.com.](../_images/bdl_license_4js_com_maintenance_key_form.jpg)

   *Four Js Online maintenance/subscription form*
4. Enter your customer code and your license number. Ensure that everything is entered correctly and click
   Submit. 

   A new page displays the maintenance/subscription key.

Next, you need to install the maintenance/subscription key.
