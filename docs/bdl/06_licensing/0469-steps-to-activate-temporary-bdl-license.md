# Steps to activate temporary BDL license

> You register the license with Four Js to finalize your product's license installation. To complete licensing, select the option (with or without internet) that is right for you and match it with the procedure to follow.

## Why you might be here

If you are on this page, it is likely because your temporary license has expired and you may see
an error like this:

```
ERROR(-6000): FLM-51 - The temporary license GSC-AAAAAAAB has expired.
```

Another common reason for visiting this page is that you have installed a new license but your
server does not have internet access — in this case, you need to register and activate from
another machine or device that does have internet access.

You will need the installation number from your license during activation. Choose one of the
activation methods below.

Before you begin activating the license:

1. Decide which tool (GUI or command line) you are using:
   - Genero BDL Licenser (GUI application)
   - fglWrt (command line tool).
2. Determine if you have internet access from the machine where you are
   licensing the product.
3. Use Table 1 to choose your licensing option, and select the
   procedure to follow.

| You are using ... | Procedure to follow |
| --- | --- |
| Genero BDL Licenser with internet | See [Activate your BDL license using GUI and internet](0470-activate-license-using-gui-internet.md "If a Genero Business Development Language (BDL) license has been installed, you can activate it using the Genero licensing graphical interface. The license is registered with Four Js via the internet and the installation and maintenance/subscription key is installed."). |
| Genero BDL Licenser without internet. | See [Activate your BDL license using GUI without internet](0471-activate-license-using-gui-no-internet.md "Without internet access, you register the license with Four Js from another machine via the internet, or by phone. Then activate your license using the user interface."). |
| fglWrt command line tool with internet. | See [Activate your BDL license from the command line (via internet)](0472-activate-license-with-fglwrt-internet.md "If a Genero Business Development Language (BDL) license has been installed, you can activate it using the command fglWrt -k auto. The license is registered with Four Js via the internet and the installation and maintenance/subscription key is installed."). |
| fglWrt command line tool without internet. | See [Activate your BDL license from the command line (no internet)](0473-activate-license-with-fglwrt-no-internet.md "Without internet access, you register the license with Four Js from another machine via the internet, or by phone. Then activate your BDL license using the fglWrt command line tool."). |
