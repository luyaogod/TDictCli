# License BDL using GUI and internet

> You can license a Genero Business Development Language (BDL) product using the Genero licensing graphical interface.

**Internet is required**

**Before you begin:** Internet
access is required to activate the license; a temporary installation does not require
internet.

1. Launch the Genero licensing graphical interface:
   - It may launch automatically when you finish installing your
     product.
   - From Genero Studio, select Tools > Genero Tools > Genero BDL Licenser.
   - From the Window Start menu, select the Genero BDL Licenser tool from
     your Four Js program list.

   The licensing page opens in a Web browser.

   ![Genero user interface for licensing your product and checking license status. The information displayed shows that no license is installed.](../_images/bdl_licensing_ui_no_license_v7_file.png)

   *Genero BDL Licenser Page*
2. Enter the license details using one of these options:
   1. Click Browse, select the license file, then click Install
      License.
   2. Enter the license number, license key, and *either* the maintenance/subscription key *or* the customer code; then click
      Install License .

**Register the license**

3. If your access to the internet is through a proxy, select the Network proxy
   settings checkbox and enter the details.
4. Enter the customer code (if not already entered) and click Activate
   License.

   ![Image shows the licenser with the customer code entered and the Activate license key highlighted](../_images/bdl_licensing_ui_activate_license_internet.png)

   *Example activating the license over internet*

   Your license has been installed and activated.
5. Click Quit Licensing to log out and close the licensing
   application.
