# Uninstall license from command line

> Use the fglWrt -d command to uninstall your Genero BDL product license.

1. At the command line enter the command: 

   ```
   fglWrt -d
   ```
2. Enter "`y`" when prompted if you really want to uninstall the
   license.

   The license is uninstalled. A message confirms the license is uninstalled.
