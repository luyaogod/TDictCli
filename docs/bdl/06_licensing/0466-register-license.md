# Register your license

> To validate your license, you must register it on the Four Js website. You can access the website from any machine or smart phone.

**About this task:**
> **Important:**
>
> If you can use the option to install the license via the internet (for example, `fglWrt``--install-license-string license-string auto`), then you do not need to
> perform this task.

**Before you begin:**

- Get your **installation number** from the output of the following
  command:

  ```
  license_controller -a info license
  ```

  Where license\_controller is
  fglWrt (for Genero Enterprise), or greWrt (for Genero Report
  Engine (GRE), depending on which product you are licensing.
- You must also have the following:
  - Customer code
  - License number
  - License keyTypically, these are delivered by email with your product. If you do not have them, contact your local sales office.

1. Open your browser and navigate to the [Four Js](https://4js.com/support/registration/) web site.
2. Navigate to the Support  >  License your products page.

   The **Online registration** form displays.

   ![The image shows the Online registration form on the License your products page on the Four Js website at https://4js.com.](../_images/4js_com_online_registration.jpg)

   *Four Js Online Registration Page*
3. Complete the **Online registration** form, ensure that everything is entered correctly, and select Submit. 

   A new page informs you that your license has been registered and provides you
   with:
   - Installation key
   - maintenance/subscription key

At this point, you need to install the installation and maintenance/subscription keys.
