# Extending the language

> These topics cover extending Genero Business Development Language with other languages and external components.


## Child topics

- [The Java interface](2655-the-java-interface.md): The Java interface allows you to import Java classes and instantiate Java objects in your programs.
- [C-Extensions](2703-c-extensions.md): With C-Extensions, you can bind your own C libraries in the runtime system, to call C function from the application code.
- [User-defined front calls](2718-user-defined-front-calls.md): Front-ends can be extended with custom functions to access specific features.
