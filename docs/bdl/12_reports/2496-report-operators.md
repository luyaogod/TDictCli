# Report operators

> Report operators can be used to print dynamic report information.


## Child topics

- [LINENO](2497-lineno.md): Contains the current line number in a report.
- [PAGENO](2498-pageno.md): Contains the current page number in a report.
- [SPACES](2499-spaces.md): Generates the given number of blank characters.
- [WORDWRAP](2500-wordwrap.md): Splits a character string to match a given margin limit.
