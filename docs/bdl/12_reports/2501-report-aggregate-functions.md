# Report aggregate functions

> Report aggregate functions can be used to compute data.


## Child topics

- [COUNT](2502-count.md): Counts a number of rows in a report based on a condition.
- [PERCENT](2503-percent.md): Calculates the percentage of rows matching a condition.
- [SUM](2504-sum.md): Calculates the total of a report parameter based on a condition.
- [AVG](2505-avg.md): Calculates the average of a report parameter base on a condition.
- [MIN](2506-min.md): Calculates the minimum value of a report parameter based on a condition.
- [MAX](2507-max.md): Calculates the maximum value of a report parameter based on a condition.
