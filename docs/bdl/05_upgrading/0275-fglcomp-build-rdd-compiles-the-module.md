# fglcomp --build-rdd compiles the module

> fglcomp --build-rdd now creates both the .42m and .rdd files.

Before version 2.21, `fglcomp --build-rdd` only produced the
.rdd data definition file.

This option is now a compilation option. Both .42m and
.rdd files are created at the same time.
