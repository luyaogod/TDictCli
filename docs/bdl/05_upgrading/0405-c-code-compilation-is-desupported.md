# C-Code compilation is desupported

> The compiler of Genero Business Development Language does not support C-Code generation.

Four Js Business Development Suite (BDS) fglcomp compiled to both P-Code or C-Code. The compiler
of Genero Business Development Language does not support C-Code generation. Only P-Code
generation is supported by Genero BDL.

If you experience performance problems when comparing Genero BDL to Four Js BDS, please contact
your local support center.
