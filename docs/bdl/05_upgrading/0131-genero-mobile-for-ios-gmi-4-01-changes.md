# Genero Mobile for iOS (GMI) 4.01 changes

> Modifications to consider when using Genero Mobile for iOS.

> **Note:**
>
> This topic describes features changes in the GMI 4.01 product. See also the Mobile section in
> [Genero BDL 4.01 New Features page](0059-bdl-4-01-new-features.md "Features added in 4.01 releases of the Genero Business Development Language.").

## GMI 4.01 with FGLGWS 4.01

> **Important:**
>
> The GMI version 4.01 is built on FGLGWS 4.01 and therefore, strongly tied to
> this Genero BDL version.

## Changes in earlier versions

Make sure to check the upgrade notes of earlier versions, to not miss changes introduced in
maintenance releases. For more details, see [Changes in GMI 1.40 / BDL 3.20](0160-genero-mobile-for-ios-gmi-1-40-changes.md "Modifications to consider when using Genero Mobile for iOS.").

Notable changes introduced in maintenance releases:

- The `--update` option of gmibuildtool --install [New option --update for gmibuildtool](0160-genero-mobile-for-ios-gmi-1-40-changes.md), is available in GMI 4.01.04 and GMI 1.40.14.
