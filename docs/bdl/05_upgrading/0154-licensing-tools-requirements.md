# Licensing tools requirements

> Genero BDL V3.21 can be used with FLM V6 or V7.

Genero BDL 3.21 is shipped with version 6 of FourJ's *license tools*
(fglWrt).

When using the FourJ's License Manager (FLM), you need FLM version 6.

In order to use the FourJ's License Manager (FLM) version 7, you must install
the version 7 of the FourJ's license tools into the FGLDIR directory.

For more information, refer to the Four Js License Manager User Guide.
