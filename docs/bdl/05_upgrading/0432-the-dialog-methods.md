# The Dialog:: methods

> Review your code and replace Dialog:: calls with the new ui.Dialog API.

Four Js Business Development Suite (BDS) provides the `Dialog::` functions to
control interactive instructions.

Genero Business Development Language provides the `ui.Dialog` built-in class.

Review your code and replace `Dialog::` calls with the new
`ui.Dialog` API.
