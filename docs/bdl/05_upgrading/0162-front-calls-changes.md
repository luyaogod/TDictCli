# Front calls changes

> Modifications to consider when using front calls.

## `monitor.update` parameter for elevation prompt (GDC only)

Starting with GDC 3.10.19, the [`monitor.update`](../15_library-reference/3427-monitor-update.md "Starts the GDC update.") front call supports a third parameter to specify if the
elevation prompt must be displayed, when the update process needs administrator permission.
