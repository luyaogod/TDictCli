# Genero Mobile for iOS (GMI) 4.00 changes

> Modifications to consider when using Genero Mobile for iOS.

> **Note:**
>
> This topic describes features changes in the GMI 4.00 product. See also the Mobile section in
> [Genero BDL 4.00 New Features page](0060-bdl-4-00-new-features.md "Features added in 4.00 releases of the Genero Business Development Language.").

## GMI 4.00 with FGLGWS 4.00

> **Important:**
>
> The GMI version 4.00 is built on FGLGWS 4.00 and therefore, strongly tied to
> this Genero BDL version.

## iOS specific configuration options

The listview row configuration attributes `ACCESSORYTYPE`,
`DETAILACTION` are no longer supported.

## Changes in earlier versions

Make sure to check the upgrade notes of earlier versions, to not miss changes introduced in
maintenance releases. For more details, see [Changes in GMI 1.40 / BDL 3.20](0160-genero-mobile-for-ios-gmi-1-40-changes.md "Modifications to consider when using Genero Mobile for iOS.").
