# Web components changes

> Modifications to consider when using web components.

## fglsvgcanvas: More interaction events

Starting with Genero BDL version 3.20.12 (WCG 1.00.20), you can define actions to detect [double-click](../11_user-interface/2421-the-fglsvgcanvas-web-component.md) and [right-click](../11_user-interface/2421-the-fglsvgcanvas-web-component.md) on SVG elements.
