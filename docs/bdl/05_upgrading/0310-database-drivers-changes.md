# Database drivers changes

> Desupported database drivers.

## Databases / ODI drivers desupported in versions 2.00:

- Adabas D 12 (dbmabd12)
- PostgreSQL 7 (dbmpgs7x)
- SQL Server 7 (dbmmsv7x)
