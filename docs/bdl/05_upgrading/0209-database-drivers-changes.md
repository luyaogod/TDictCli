# Database drivers changes

> Desupported database drivers.

## Databases / ODI drivers desupported in version 3.00:

- SAP ASE 15.x (`dbmase_15`). New SAP® ASE 16.x version is now supported.
  > **Important:**
  >
  > SAP ASE is now fully desupported
  > in all Genero versions.
- Oracle® Database 10.1 and 10.2
  (`dbmora_10`)

  > **Note:**
  >
  > This driver is no longer available for Linux® PowerPC
  > 32/64 platforms, because Oracle has
  > desupported this platform.
