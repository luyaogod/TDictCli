# Licensing tools requirements

> Genero BDL V6.00 must be used with FLM V7.

Genero BDL 6.00 is shipped with the version 7 of FourJ's license tools
(fglWrt).

When using the FourJ's License Manager (FLM), you need FLM version 7.

For more information, refer to the Four Js License Manager User Guide.
