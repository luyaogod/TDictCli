# Web components changes

> Modifications to consider when using web components.

## Changes in earlier versions

Make sure to check the upgrade notes of earlier versions, to not miss changes introduced in
maintenance releases. For more details, see [Web component changes in BDL 3.20](0163-web-components-changes.md "Modifications to consider when using web components.").

Notable changes introduced in maintenance releases:

- fglsvgcanvas: [Double-click and right-click mouse events](0163-web-components-changes.md), also available since WCG 4.00.01.
