# VM and front-end compatibility

> Always combine Genero Virtual Machine with the latest compatible Front-End.

Graphical User Interface new features and bug fixes usually require modifications inside the
runtime system and front-ends.

The [product version number](0086-version-number-meaning.md "A product version number identifies a specific release of the software product.") has the form
`X.YY.ZZ` and identifies a given Genero BDL release as well as front-end
releases.

Starting with front-ends of version 5.00, it is possible to mix FGL runtime and front end
versions that do not have the same major version number. However, to benefit from the recent
user interface features and bug fixes, always consider to install the latest FGL and front
end versions.
