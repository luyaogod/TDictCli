# Compiled string files (.42s)

> The file extension of compiled string files is new .42s.

Starting with version 1.30, compiled localized string files use now the file extension
.42s.

Before version 1.30, the file extension was .4ls.

See [Localized strings](../09_advanced-features/0901-localized-strings.md "Localized strings provide a means of writing applications in which the text of strings can be customized on site.").
