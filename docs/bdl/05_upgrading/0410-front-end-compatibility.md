# Front-end compatibility

> With Genero BDL, you must use one of the Genero front-ends

The WTK, WebFE and JavaFE front-ends are not compatible with the Genero fglrun runtime system.
When migrating to Genero Business Development Language (BDL), you must use one of the Genero
front-ends.

The UNIX™ version of Genero no longer includes the
fglX11d front-end. You must use the GDC front-end on UNIX.
