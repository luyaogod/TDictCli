# Genero Mobile for iOS (GMI) 5.01 changes

> Modifications to consider when using Genero Mobile for iOS.

> **Note:**
>
> This topic describes features changes in the GMI 5.01 product. See also the Mobile section in
> [Genero BDL 5.01 New Features page](0057-bdl-5-01-new-features.md "Features added in 5.01 releases of the Genero Business Development Language.").

## GMI 5.01 with FGLGWS 5.01

> **Important:**
>
> The GMI version 5.01 is built on FGLGWS 5.01 and therefore, strongly tied to
> this Genero BDL version.
