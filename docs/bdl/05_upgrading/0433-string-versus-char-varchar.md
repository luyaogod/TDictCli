# STRING versus CHAR/VARCHAR

> Genero BDL supports the STRING data type in addition to CHAR and VARCHAR. While the STRING data type is useful in certain situations, there are times when you should use CHAR or VARCHAR instead.

This topic also concerns IBM®
Informix® 4GL migration,
see the [I4GL Migration](0379-string-versus-char-varchar.md "Genero BDL supports the STRING data type in addition to CHAR and VARCHAR. While the STRING data type is useful in certain situations, there are times when you should use CHAR or VARCHAR instead.") page
