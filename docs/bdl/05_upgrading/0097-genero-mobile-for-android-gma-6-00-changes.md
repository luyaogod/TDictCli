# Genero Mobile for Android (GMA) 6.00 changes

> Modifications to consider when using the Genero Mobile for Android™.

> **Note:**
>
> This topic describes feature changes in the GMA 6.00 product. See also the Mobile section in
> [Genero BDL 6.00 New Features page](../02_what-s-new-in-6-00/0002-what-s-new-in-6-00.md "Features added in 6.00 releases of the Genero Business Development Language.").

## GMA 6.00 with FGLGWS 6.00

> **Important:**
>
> The GMA version 6.00 is built on FGLGWS 6.00 and therefore, strongly tied to this Genero BDL
> version.

Make sure to check the upgrade notes of earlier versions, to not miss changes introduced in
maintenance releases. For more details, see [Changes in GMA 5.01 / BDL 5.01](0108-genero-mobile-for-android-gma-5-01-changes.md "Consider these modifications when you use Genero Mobile for Android.").
