# Presentation styles changes

> Modifications to consider when using presentation styles.

## `showVirtualKeyboard` attribute

Starting with GBC 5.00.11, you can use the new `showVirtualKeyboard` style
attribute for `EDIT`, `BUTTONEDIT`, `SPINEDIT` and
`TEXTEDIT` fields, to control how the virtual keyboard appears on mobile devices.

See [showVirtualKeyboard](../11_user-interface/1637-edit-style-attributes.md).

## `headerPosition` attribute

Starting with GBC 5.00.11, the new `headerPosition` style attribute can be used
with tables, to specify the relative position of column titles.

See [headerPosition](../11_user-interface/1648-table-style-attributes.md).
