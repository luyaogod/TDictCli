# Java Inteface changes

> There are changes in support of Java in Genero 3.10.

## Genero BDL supports Java SE 6 to Java SE 10 and 11

Starting with version 3.10.14, Genero BDL supports now Java SE 10 and 11 when using the
Java Interface.

> **Important:**
>
> The minimum required version to use the BDL Java Interface is
> Java SE 6.

For more details, see [Java software requirements for FGL](../14_extending-the-language/2658-java-software-requirements-for-fgl.md).
