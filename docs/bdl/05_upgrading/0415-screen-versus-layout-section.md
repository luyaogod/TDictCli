# SCREEN versus LAYOUT section

> When writing new programs for GUI applications, it is recommended that you use a LAYOUT section instead of SCREEN. However, the SCREEN section is still supported to be used to design TUI mode forms.

This topic also concerns IBM®
Informix® 4GL migration,
see the [I4GL Migration](0352-screen-versus-layout-section.md "When writing new programs for GUI applications, it is recommended that you use a LAYOUT section instead of SCREEN. However, the SCREEN section is still supported to be used to design TUI mode forms.") page
for mode details.
