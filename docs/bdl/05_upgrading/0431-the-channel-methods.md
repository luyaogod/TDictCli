# The Channel:: methods

> Review your code and replace Channel:: calls with the new base.Channel API.

Four Js Business Development Suite (BDS) provides the `Channel::` functions to do
file I/O.

Genero Business Development Language provides file, socket and process I/O with the
`base.Channel` built-in class.

Review your code and replace `Channel::` calls with the new
`base.Channel` API.
