# Presentation styles changes

> Modifications to consider when using presentation styles.

## `Form.resetFormSize` style attribute

Starting with Genero BDL 2.30, the Form presentation style `resetFormSize` can be
used to control the window resizing behavior when doing successive `OPEN FORM` /
`DISPLAY FORM`.

> **Note:**
>
> This style attribute is desupported. See [Presentation style changes in
> V4.00](0143-presentation-styles-changes.md "Modifications to consider when using presentation styles.").
