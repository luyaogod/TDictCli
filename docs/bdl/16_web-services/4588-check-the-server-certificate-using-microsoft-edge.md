# Check the server certificate using Microsoft Edge

> This procedure allows you to check the server certificate using Microsoft Edge.

1. Type the HTTPS URL.
2. Once the page is displayed, click on the padlock icon.

   The About window displays.
3. Click on the option with the padlock icon from the menus displayed.
4. In the dialog that opens, click the Show certificate  icon on the
   toolbar.

   The Certificate viewer dialog opens
5. In the Details tab, view the Certificate Hierarchy.

   ![Screenshot showing Details tab in Certificate Viewer](../_images/certificate_edge.png)

   *Certificate Viewer; Details tab.*
