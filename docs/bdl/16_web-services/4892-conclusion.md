# Conclusion

In a SOA environment, you can call any Java library from Genero using Web Services, and without a
strong dependency to a JVM. This follows SOA principles - it allows you to reuse the Java library in
another BDL application without any new development, you can update the Java part without
recompiling any .4gl source, and integrate any function available from a SOA
platform.
