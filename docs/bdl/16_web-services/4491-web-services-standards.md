# Web services standards

> Web services standards are defined by the World Wide Web and other organizations.

For more information about these standards, refer to the "Web services" section of <http://www.w3.org>. The Genero Web Services package supports
the WSDL 1.1 specification of March 15, 2002 as well as some previous specifications.

Starting with FGLGWS version 3.20, the GWS supports the OpenAPI Specification (OAS), based on the
original Swagger specification, as the standard for defining and describing RESTful APIs. GWS
supports version 3.0 of the OpenAPI Specification. For more information, see <http://www.openapis.org/>.

The standards involved in what is commonly called "Web services" include XML, JSON, XML Schema,
SOAP, REST, WSDL, and HTTP.

## Child topics

- [XML](4492-xml.md): XML (eXtensible Markup Language) defines a machine-independent way of exchanging data.
- [JSON](4493-json.md): JavaScript Object Notation (JSON) defines a machine-independent way of exchanging data.
- [XML schema](4494-xml-schema.md): XML Schema defines the elements, entities, and content model of an XML document.
- [SOAP](4495-soap.md): Simple Object Access Protocol (SOAP) is a communication protocol that defines an XML data flow between a server and a client.
- [REST](4496-rest.md): Representational State Transfer (REST) is a Web standard architecture that provides a method for communication between a Web service and a client over HTTP.
- [WSDL](4497-wsdl.md): Web Services Description Language (WSDL) is an XML-based language that describes the services offered by a SOAP server.
- [HTTP](4498-http.md): Hypertext Transfer Protocol (HTTP).
