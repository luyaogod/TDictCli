# Code a RESTful client application (high-level framework)

> Create, configure and deploy a Web service client application using the Genero high-level framework.

A client application demo can be found at
$FGLDIR/demo/WebServices/books.

## Child topics

- [Understanding the OpenAPI description of a Genero RESTful service](4774-understanding-the-openapi-description-of-a-genero-restful-se.md): The OpenAPI description provides a structured view of your RESTful web service, including service information, paths, parameters, and the request and response bodies generated from your Genero BDL code.
- [Information needed to generate a REST stub file](4781-before-generating-the-stub-file.md): You need the OpenAPI description of the RESTful service before generating the stub file or implementing client-side calls.
- [Create the client application](4785-create-the-client-application.md): Prepare the client application that uses the generated stub to call the REST service.
- [Change REST client behavior at runtime](4792-change-rest-client-behavior-at-runtime.md): Use the global endpoint record to change the REST client behavior at runtime without modifying the generated client stub.
