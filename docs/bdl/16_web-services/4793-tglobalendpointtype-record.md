# tGlobalEndpointType record

> Use the tGlobalEndpointType record to change the REST client behavior at runtime, such as updating the server address or connection settings.

The [client stub](4782-rest-stub-file-overview.md "The stub file provides client-side functions that call the operations of a RESTful Web service. It acts as a proxy layer between your client application and the service.") generated by the
fglrestful tool includes the `tGlobalEndpointType` record. This
record provides fields that let you modify REST client behavior at runtime without regenerating the
stub.

## Record definition

The following code defines the `tGlobalEndpointType` record. For more details, go
to [Compression in a REST web services client](4551-compression-in-a-rest-web-services-client.md "Send and receive compressed requests from a REST web services client.").

```
TYPE tGlobalEndpointType RECORD # REST Endpoint
      Address RECORD 
         Uri STRING 
      END RECORD,
      Binding RECORD 
         Version STRING, # HTTP Version (1.0 or 1.1)
         ConnectionTimeout INTEGER,
         ReadWriteTimeout INTEGER, 
         CompressRequest STRING 
      END RECORD
END RECORD
```

## Fields

The fields of the `tGlobalEndpointType` record are:

- `Address.Uri`: The URL of the server.
- `Binding.Version`: The HTTP version to use (1.0 or 1.1; default is 1.1).
- `Binding.ConnectionTimeout`: Maximum number of seconds to wait for the server connection.
- `Binding.ReadWriteTimeout`: Maximum number of seconds to wait for a read or write operation.
- `Binding.CompressRequest`: Compression option for the Content-Encoding header (gzip or deflate).

## Public endpoint variable

The client stub defines a public variable named `Endpoint` of type `tGlobalEndpointType`. The generator initializes this variable with the service URL.

```
PUBLIC DEFINE Endpoint
tGlobalEndpointType
= (Address: (Uri: "http://localhost:8090/MyService"))
```
