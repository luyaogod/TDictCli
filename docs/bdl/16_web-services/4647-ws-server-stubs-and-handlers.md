# WS server stubs and handlers

> Describes using a server stub from a compatible Web service that you can use in your GWS server application.

Sample Web services can be found through UDDI registries [(http://uddi.xml.org)](http://uddi.xml.org/), or on other sites such as
XMethods .

## Child topics

- [Generating stub file for a GWS server](4648-generating-stub-file-for-a-gws-server.md): Use the fglwsdl -s tool server option to generate the BDL server stub from a WSDL.
- [Server handlers](4650-server-handlers.md): Create and register your callback handlers (request, and response) to modify the WSDL.
- [Example output](4651-example-output.md): What you can expect to find in the server stub files.
- [Writing your functions](4652-writing-your-functions.md): Write functions that implement the functions in the stub modules. It allows you to create your own version of the function.
