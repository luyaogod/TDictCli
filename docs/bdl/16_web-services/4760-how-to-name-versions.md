# How to name versions

> There are no absolute rules to naming versions, but there are best practices.

The version names you choose should be a simple name (such as
"`v1`") that provides a sequence. The sequence approach allows you to
organize your versions in a logical manner that makes sense to you.

The version need not be numeric, nor be specified using
the "`v[x]`" syntax. Alternatives that you find meaningful
can be used, such as dates or project names. The only criteria is that they be flexible to
change as the versions change.
