# HTTP operation attributes (Verbs)

> Attributes that map an HTTP operation or verb action in a function to a REST resource.

> **Important:**
>
> One HTTP verb action such as
> `WSGet`, `WSPost`, `WSPut`, `WSDelete`,
> etc. is a mandatory attribute in a REST Web service function.

**Related concepts**  

[Define your resource operations](4724-define-your-resource-operations.md "Operations are the HTTP verbs used to manipulate the resources of your Web service.")

## Child topics

- [WSDelete](4815-wsdelete.md): In order to remove an existing resource, you set the WSDelete attribute.
- [WSGet](4816-wsget.md): In order to retrieve a resource, you set the WSGet attribute.
- [WSHead](4817-wshead.md): In order to retrieve resource headers, you define the WSHead attribute.
- [WSOptions](4818-wsoptions.md): In order to retrieve the HTTP request methods supported by the server or the resource, you define the WSOptions attribute.
- [WSPatch](4819-wspatch.md): In order to partially update an existing resource, you define the WSPatch attribute.
- [WSPost](4820-wspost.md): In order to create a new resource, you set the WSPost attribute.
- [WSPut](4821-wsput.md): Update an existing resource with the WSPut attribute.
- [WSTrace](4822-wstrace.md): You define the WSTrace attribute for debugging purposes.
