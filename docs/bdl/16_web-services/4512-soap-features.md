# SOAP features

> The GWS provides support for SOAP versions and for managing SOAP fault.


## Child topics

- [SOAP 1.1 and 1.2](4513-soap-1-1-and-1-2.md): GWS is able to communicate with Web services provided with SOAP 1.1 or SOAP 1.2.
- [SOAP Fault](4514-soap-fault.md): Genero Web Services supports SOAP's built-in error handling.
