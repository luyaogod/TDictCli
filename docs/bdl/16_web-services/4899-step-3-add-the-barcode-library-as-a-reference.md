# Step 3: Add the barcode library as a reference

Right-click on the Solution Explorer, select Add
Reference and use the Browse panel to enter the location of the
barcode library called BarcodeLib.Barcode.dll:

![Screenshot after adding Barcodelib.Barcode.dll as reference](../_images/AddReference.jpg)

By default, the barcode library will be copied to the right place when deploying on the IIS web
server.

In the next step we add the `buildImage` method, [Step 4: Add the buildImage method](4900-step-4-add-the-buildimage-method.md).
