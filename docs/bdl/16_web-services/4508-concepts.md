# Concepts

> These topics cover various Genero Web Services concepts.


## Child topics

- [Genero Web Services APIs](4509-web-services-apis.md): This section provides overview information on the Web services Application Program Interfaces (APIs).
- [SOAP features](4512-soap-features.md): The GWS provides support for SOAP versions and for managing SOAP fault.
- [Stateful SOAP Web services](4517-stateful-soap-web-services.md): The GWS provides support for stateful service. Different options for implementing SOAP stateful services are described.
- [Data compression in GWS](4545-data-compression-in-gws.md): GWS SOAP and RESTful web services support data compression.
- [SOAP multipart style requests in GWS](4553-soap-multipart-style-requests-in-gws.md): This topic describes multipart support with SOAP Genero Web Services
- [Message Transmission Optimization Mechanism (MTOM)](4554-mtom.md): Use MTOM to efficiently send binary data to and from SOAP Web services.
- [swaRef (SOAP with attachments using wsi:swaRef)](4555-swaref.md): swaRef is a specific way for sending and receiving attachments in SOAP. It is used when you have to transfer files as attachment and locate on disk.
