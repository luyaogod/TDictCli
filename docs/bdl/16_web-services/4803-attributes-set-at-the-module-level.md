# Attributes set at the module level

> Attributes that apply to the whole Web service (at the module level).


## Child topics

- [WSInfo](4804-wsinfo.md): Defines general metadata about the REST service.
- [WSError](4805-wserror.md): Defines a description for an HTTP status code returned by the service.
- [WSContext](4806-wscontext.md): Provides a dictionary of request‑specific context values for the current REST request, available to all operations in the module.
- [WSScope (module)](4807-wsscope-module.md): Defines the access scope required to call any REST operation in the module.
- [WSVersion (module)](4808-wsversion-module.md): Sets the version of the REST service for OpenAPI documentation.
- [WSVersionMode](4809-wsversionmode.md): Specifies how the service version is selected for OpenAPI generation (URI, header, or query).
- [WSTypeDescription](4810-wstypedescription.md): Provides a description for a user‑defined type in the REST service.
- [WSPreProcessing](4811-wspreprocessing.md): Specify functions in a REST web service module that are used as preprocessing request handlers.
- [WSPostProcessing](4812-wspostprocessing.md): Specify functions in a REST web service module that are used as postprocessing request handlers.
