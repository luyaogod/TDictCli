# Compression in a SOAP Web services server

> Send and receive compressed requests from a Web services server.

If the Genero Web Services client accepts compression, the Genero Web Services server will
reply with a compressed response.

To disable compression, you must disable compression in the Genero Application Server
$FGLASDIR/etc/imt.cfg file. See the Compression in Genero
Application Server page in Genero Application Server User Guide for more
information.
