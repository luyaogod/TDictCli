# Change REST client behavior at runtime

> Use the global endpoint record to change the REST client behavior at runtime without modifying the generated client stub.

The high-level Genero Web Services REST client provides a global record type, [tGlobalEndpointType record](4793-tglobalendpointtype-record.md "Use the tGlobalEndpointType record to change the REST client behavior at runtime, such as updating the server address or connection settings."), that you can use to change the client behavior at runtime. This lets you adjust settings such as the server endpoint without updating or regenerating the client stub.
