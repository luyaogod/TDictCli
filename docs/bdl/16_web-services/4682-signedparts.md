# SignedParts

> The SignedParts section of the policy specifies which part of the message should be signed.

```
<sp:SignedParts xmlns:sp="http://schemas.xmlsoap.org/ws/2005/07/securitypolicy">
<sp:Body />
```

- Only the body needs to be signed
