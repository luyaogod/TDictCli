# Attributes set on parameters and returns

> Attributes that affect the input parameters and return values of the function.


## Child topics

- [Attributes set on both input and output](4837-attributes-set-on-both-input-and-output.md): Attributes defining parameters or return values handling headers and file attachment in REST functions.
- [Attributes related to function parameters](4840-attributes-related-to-function-parameters.md): Various attributes you use in conjunction with other attributes to specify methods for naming and describing parameters and functions.
