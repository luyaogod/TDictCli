# Quick start 3: RESTful client application

> This is a quick step-by-step guide to creating a RESTful Web service client app using the high-level framework.

It is assumed you have followed the [Quick start 2: RESTful server application, part 2](4714-quick-start-2-restful-server-application-part-2.md "This quick start provides step-by-step instruction for adding functionality to the RESTful Web service server application created by the previous quick start.") quick start to create the Web service
with all its functions. At the end of that quick start, you left the Web service application
running.

In this quick start, you create a Web service client app to work with the Web service. You need
to:

1. [Generate the stub
   file](4718-generate-the-stub-file.md "Use the fglrestful tool to generate the client stub from a REST Web service URL.") from the Web service.
2. [Create a client
   app](4719-create-the-client-module.md "Create a client app that interacts with the Genero Web service through calls to functions in the stub file.") that calls functions in the stub file.
3. [Run the client app](4720-compile-and-run-the-client.md "Run your Genero RESTful Web service client app to display to the Genero Desktop Client (GDC).") to
   retrieve, add, update, and delete customers by sending requests to the Web service.
