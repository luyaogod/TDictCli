# Check the server certificate using FireFox

> Check the server certificate using FireFox.

1. Type the HTTPS URL.
2. Once the page is displayed, click on the padlock icon.

   An About dialog window displays.
3. Click on the option with the padlock icon from the menu.
4. Click on the More Information menu option.

   The Page info page opens.
5. From the Security tab, click View
   Certificate.

   The Certificate page opens
6. Click on a tab to view a certificate in the certificate hierarchy.
