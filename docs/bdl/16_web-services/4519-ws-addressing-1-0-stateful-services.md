# WS-Addressing 1.0 stateful services

> WS-Addressing 1.0 uses the WS-Addressing EndpointReference type as a state variable to maintain a stateful service.

The `EndpointReference` type is independent from the transport layers. (See [WS-Addressing 1.0
EndpointReferenceType](http://www.w3.org/TR/ws-addr-core/#eprs)). The session state is conveyed from the client to the server as
WS-Addressing 1.0 reference parameters.
