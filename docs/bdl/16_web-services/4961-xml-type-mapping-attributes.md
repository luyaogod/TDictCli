# XML type mapping attributes

The attributes listed in this table cannot have values.

| Attribute | Definition |
| --- | --- |
| [XSDAnySimpleType](4962-xsdanysimpletype.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `simpleType`. |
| [XSDAnyType](4963-xsdanytype.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `anyType`. |
| [XSDAnyURI](4964-xsdanyuri.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `anyURI`. |
| [XSDBase64binary](4965-xsdbase64binary.md) | Map BDL `BYTE` to the XML Schema `base64binary`. |
| [XSDBoolean](4966-xsdboolean.md) | Map BDL `BOOLEAN`, `SMALLINT` or `INTEGER` to XML Schema `boolean`. |
| [XSDByte](4967-xsdbyte.md) | Map BDL `TINYINT`, `SMALLINT` or `BIGINT` to XML Schema `byte`. |
| [XSDDate](4968-xsddate.md) | Map BDL `DATE` or `DATETIME` to XML Schema `date`. |
| [XSDDateTime](4969-xsddatetime.md) | Map BDL `DATETIME` to XML Schema `dateTime`. |
| [XSDDecimal](4970-xsddecimal.md) | Map BDL `DECIMAL` to XML Schema `decimal`. |
| [XSDDouble](4971-xsddouble.md) | Map BDL `FLOAT` to XML Schema `double`. |
| [XSDDuration](4972-xsdduration.md) | Map BDL `INTERVAL` to XML Schema `duration`. |
| [XSDEntities](4973-xsdentities.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `entities`. |
| [XSDEntity](4974-xsdentity.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `entity`. |
| [XSDFloat](4975-xsdfloat.md) | Map BDL `SMALLFLOAT` to XML Schema `float`. |
| [XSDGday](4976-xsdgday.md) | Map BDL `DATETIME` to XML Schema `gDay`. |
| [XSDGMonth](4977-xsdgmonth.md) | Map BDL `DATETIME` to XML Schema `gMonth`. |
| [XSDGMonthDay](4978-xsdgmonthday.md) | Map BDL `DATETIME` to XML Schema `gMonthDay`. |
| [XSDGYear](4979-xsdgyear.md) | Map BDL `DATETIME` to XML Schema `gYear`. |
| [XSDGYearMonth](4980-xsdgyearmonth.md) | Map BDL `DATETIME` to XML Schema `gYearMonth`. |
| [XSDHexBinary](4981-xsdhexbinary.md) | Map BDL `BYTE` to XML Schema `hexBinary`. |
| [XSDID](4982-xsdid.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `id`. |
| [XSDIDREF](4983-xsdidref.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `idRef`. |
| [XSDIDREFS](4984-xsdidrefs.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `idRefs`. |
| [XSDInt](4985-xsdint.md) | Map BDL `INTEGER` or `BIGINT` to XML Schema `int`. |
| [XSDInteger](4986-xsdinteger.md) | Map BDL `DECIMAL` to XML Schema `integer`. |
| [XSDLanguage](4987-xsdlanguage.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `language`. |
| [XSDLong](4988-xsdlong.md) | Map BDL `BIGINT` or `DECIMAL` to XML Schema `long`. |
| [XSDNCName](4989-xsdncname.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `NCName`. |
| [XSDName](4990-xsdname.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `Name`. |
| [XSDNegativeInteger](4991-xsdnegativeinteger.md) | Map BDL `DECIMAL` to XML Schema `negativeInteger`. |
| [XSDNMTOKEN](4992-xsdnmtoken.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `NMToken`. |
| [XSDNMTOKENS](4993-xsdnmtokens.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `NMTokens`. |
| [XSDNonNegativeInteger](4994-xsdnonnegativeinteger.md) | Map BDL `DECIMAL` to XML Schema `nonNegativeInteger`. |
| [XSDNonPositiveInteger](4995-xsdnonpositiveinteger.md) | Map BDL `DECIMAL` to XML Schema `nonPositiveInteger`. |
| [XSDNormalizedString](4996-xsdnormalizedstring.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `normalizedString`. |
| [XSDNotation](4997-xsdnotation.md) | Not supported. |
| [XSDPositiveInteger](4998-xsdpositiveinteger.md) | Map BDL `DECIMAL` to XML Schema `positiveInteger`. |
| [XSDQName](4999-xsdqname.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `QName`. |
| [XSDShort](5000-xsdshort.md) | Map BDL `SMALLINT` or `BIGINT` to XML Schema `short`. |
| [XSDString](5001-xsdstring.md) | Map BDL `STRING`, `CHAR`, `TEXT` or `VARCHAR` to XML Schema `string`. |
| [XSDTime](5002-xsdtime.md) | Map BDL `DATETIME` to XML Schema `time`. |
| [XSDToken](5003-xsdtoken.md) | Map BDL `STRING` or `VARCHAR` to XML Schema `token`. |
| [XSDUnsignedByte](5004-xsdunsignedbyte.md) | Map BDL `SMALLINT` or `BIGINT` to XML Schema `unsignedByte`. |
| [XSDUnsignedInt](5005-xsdunsignedint.md) | Map BDL `BIGINT` or `DECIMAL` to XML Schema `unsignedInt`. |
| [XSDUnsignedLong](5006-xsdunsignedlong.md) | Map BDL `DECIMAL` to XML Schema `unsignedLong`. |
| [XSDUnsignedShort](5007-xsdunsignedshort.md) | Map BDL `INTEGER` or `BIGINT` to XML Schema `unsignedShort`. |
