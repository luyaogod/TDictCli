# Stateful SOAP Web services

> The GWS provides support for stateful service. Different options for implementing SOAP stateful services are described.


## Child topics

- [Concept](4518-concept.md): A stateful service is a service that maintains a context between a Web services client and server.
- [WS-Addressing 1.0 stateful services](4519-ws-addressing-1-0-stateful-services.md): WS-Addressing 1.0 uses the WS-Addressing EndpointReference type as a state variable to maintain a stateful service.
- [Stateful services based on HTTP cookies](4531-stateful-services-based-on-http-cookies.md): A stateful service based on HTTP cookies uses the HTTP transport protocol and its ability to transmit cookies, used as session context.
