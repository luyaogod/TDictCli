# Prerequisites

- A JRE 1.5 or above
- The Java barcode library
  (available [here](http://www.barcodelib.com/java_barcode/main.html))
  - You must add these JARs to the Java CLASSPATH: barcode.jar and
    BarcodeReader.jar
  - The trial version has some functions partially implemented.
- Download the JAX-WS framework from the Sun®
  metro project [here](http://java.sun.com/webservices/downloads/index.jsp); add this JAR to the java CLASSPATH:
  webservices-tools.jar
