# Prerequisites

- IIS (Internet Information Services) Web server
- Visual Studio Professional Edition C#
  - Visual Studio is only needed for development. Once the service is built, you can deploy on any
    IIS Web Server.
- The .NET barcode library (available [here](http://www.barcodelib.com/net_barcode/main.html))
  - The trial version has some functions partially implemented.
  - The .NET library is called BarcodeLib.Barcode.dll, and must be added to the
    Visual Studio Project.
