# Genero Web Services APIs

> This section provides overview information on the Web services Application Program Interfaces (APIs).

Web services work by responding to requests for data and returning JSON or XML documents. As JSON
and XML are simple text formats, Web services are invoked via APIs over the Hypertext Transfer
Protocol (HTTP).

Genero Web Services support SOAP and REST Web services.

## Child topics

- [SOAP Web services APIs](4510-soap-web-services-apis.md): Genero provides high-level and low-level APIs for creating SOAP Web services.
- [REST Web services APIs](4511-rest-web-services-apis.md): Genero provides BDL function attributes to define high-level REST Web services. Low-level REST web services are implemented using standard HTTP classes.
