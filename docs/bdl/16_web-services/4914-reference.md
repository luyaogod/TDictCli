# Reference

> These topics are the reference guides for Genero Web Services.


## Child topics

- [Web services FGLPROFILE configuration](4915-web-services-fglprofile-configuration.md): The configuration for the Genero Web Services is defined from entries in the FGLPROFILE file.
- [WSHelper library](4923-wshelper-library.md): The WSHelper library provides a set of functions to help with web services.
- [OAuthAPI library](4930-oauthapi-library.md): The OAuthAPI library provides a set of functions for working with access to web services using the OAuth protocol.
- [XML serialization rules and customization](4958-xml-serialization-rules-and-customization.md)
- [JSON serialization rules and customization](5048-json-serialization-rules-and-customization.md): This section describes the rules, attributes, and options used when converting BDL values to and from JSON in GWS applications.
- [Error handling in GWS calls (status)](5064-error-handling-in-gws-calls-status.md): When errors are encountered, the methods of GWS classes can throw exceptions and set the status variable with the appropriate error number.
- [Interruption handling in GWS calls (int_flag)](5065-interruption-handling-in-gws-calls-int-flag.md): Genero Web Services (GWS) tests int_flag to check if an application has been interrupted.
- [Server API functions - version 1.3 only](5066-server-api-functions-version-1-3-only.md): Server API functions can create a Web Services server in Genero BDL.
- [Configuration API functions - version 1.3 only](5074-configuration-api-functions-version-1-3-only.md): Configuration API functions can modify the behavior of the Web Services engine for the client and/or server.
- [Using fglwsdl to generate code from WSDL or XSD schemas](5079-using-fglwsdl-to-generate-code-from-wsdl-or-xsd-schemas.md): The fglwsdl tool generates Genero (.4gl) code from WSDL / XSD schemas.
