# XMLBase

Define the simple BDL variable used as the base type of an XML Schema [simpleContent](http://www.w3.org/TR/xmlschema-1/#element-simpleContent)
structure.

The attribute can be set on one and only one member of a RECORD defined with the [XMLSimpleContent](5031-xmlsimplecontent.md) attribute
