# Defining the action for a row choice

> The row choice in a SCROLLGRID can be associated with a dedicated action.

If using a `DISPLAY ARRAY` dialog to control a scrollgrid, a
double-click on a row (for a desktop client), or a tap on a row (for mobile clients) fires a default
action.

Row choice action can be customized as described in [Defining the action for a row choice](2304-defining-the-action-for-a-row-choice.md "The row choice in the DISPLAY ARRAY/INPUT ARRAY dialog can be associated with a dedicated action.").
