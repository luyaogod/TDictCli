# Unsupported scrollgrid features (mobile)

> Some scrollgrid view features are not supported on mobile devices.

The list view features not supported on mobile devices include:

- [Controlling columns layout](2323-controlling-columns-layout.md "By default, a user can position, hide, show, and resize columns in TABLE and TREE containers.")
- [Sorting rows in a list](2324-sorting-rows-in-a-list.md "List controllers implement a built-in sort. This feature can be disabled if not required.")
- [Keyboard seek to matching row](2326-keyboard-seek-to-matching-row.md "The keyboard seek feature allows a user to find a row in a read-only list, by typing characters.")
