# Using hbox tags to align form items

> The hbox tag concept has been introduced to bypass the limitations of the character-based grid in forms.

An hbox tag defines a widget container that arranges child widgets horizontally, like the
horizontal box container. All widgets inside this container are no longer dependent on the parent
grid.
