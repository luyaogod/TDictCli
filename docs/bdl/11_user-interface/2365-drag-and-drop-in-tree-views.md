# Drag and drop in tree-views

> Drag and drop is supported with a DISPLAY ARRAY controlling a TREE.

Use the `ON DRAG*` and `ON DROP` interactive blocks, to implement
drag and drop within a `DISPLAY ARRAY` controlling a `TREE`
container.

The nodes can be moved around in the same tree, can be dropped
outside the tree or can be inserted in the tree from external sources.
