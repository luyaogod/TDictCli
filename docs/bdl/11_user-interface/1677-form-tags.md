# Form tags

> Form tags define layout elements inside a grid-based container.

Form tags are place holders used inside a grid of the layout section, to define the position
and the relation between form items.

The syntax and purpose of a form tag depends on the type of form tag.

## Child topics

- [Layout tags](1678-layout-tags.md): Layout tags define layout areas for containers inside the frame of a grid-based container.
- [Item tags](1679-item-tags.md): Item tags define the position and size in a grid-based container.
- [Hbox tags](1680-hbox-tags.md): Hbox tags group several item tags within the same horizontal layout box, inside a grid-based container (GRID).
