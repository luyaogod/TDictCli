# Fonts

> A graphical application defaults to using the front-end platform theme. The front-end tries to determine the default font for the application screens.


## Child topics

- [Font families](1624-font-families.md): Use the fontFamily style attribute to define a font family.
- [Font sizes](1625-font-sizes.md): Use the fontSize style attribute to influence the size of a font.
- [Font styles](1626-font-styles.md): Use the fontStyle style attribute to define the style of a font.
- [Font weights](1627-font-weights.md): Use the fontWeight style attribute to define the aspect of a font.
