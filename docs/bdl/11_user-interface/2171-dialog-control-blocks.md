# DIALOG control blocks

> Dialog control blocks are predefined dialog triggers where you can implement specific code to control the interactive instruction.

The code may involve using [`ui.Dialog`](../15_library-reference/3169-the-dialog-class.md "The ui.Dialog class provides a set of methods to configure, query and control the current interactive instruction.")
class methods or dialog specific instructions such as [`NEXT FIELD`](1955-next-field-instruction.md) or [`CONTINUE DIALOG`](2140-continue-dialog-instruction.md).
