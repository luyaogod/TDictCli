# Topmenus

> Topmenus define typical pull-down menus that appear at the top of application forms.


## Child topics

- [Understanding topmenus](1867-understanding-topmenus.md): This is an introduction to topmenu definitions.
- [Defining the topmenu in a form file](1868-defining-the-topmenu-in-a-form-file.md): Topmenus can be defined in the form specification file within the TOPMENU section.
- [Syntax of a topmenu file (.4tm)](1869-syntax-of-a-topmenu-file-4tm.md): A .4tm topmenu file is an XML file that holds a tree of elements defining a topmenu structure.
- [Loading .4tm topmenu definition files](1870-loading-4tm-topmenu-definition-files.md): Topmenu XML definition files can be loaded at runtime.
- [Creating the topmenu dynamically](1871-creating-the-topmenu-dynamically.md): Topmenus can be created at runtime by creating the corresponding XML representation in the AUI tree.
- [Examples](1872-examples.md): Topmenu usage examples.
