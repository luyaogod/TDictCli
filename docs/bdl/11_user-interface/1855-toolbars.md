# Toolbars

> Toolbars define a bar of buttons that appears at the top of application forms.


## Child topics

- [Understanding toolbars](1856-understanding-toolbars.md): This is an introduction to toolbars definition.
- [Defining toolbars in the form file](1857-defining-toolbars-in-the-form-file.md): Toolbars can be defined in the form specification file within the TOOLBAR section.
- [Syntax of a toolbar file (.4tb)](1858-syntax-of-a-toolbar-file-4tb.md): A .4tb toolbar file is an XML file that holds a tree of elements defining a toolbar structure.
- [Loading .4tb toolbar definition files](1859-loading-4tb-toolbar-definition-files.md): Toolbar XML definition files can be loaded at runtime.
- [Creating the toolbar manually with DOM](1860-creating-the-toolbar-manually-with-dom.md): Toolbars can be created at runtime by creating the corresponding XML representation in the AUI tree.
- [Toolbars on mobile devices](1861-toolbars-on-mobile-devices.md): Toolbars can be used to control action view rendering on mobile devices.
- [Examples](1862-examples.md): Toolbar usage examples.
