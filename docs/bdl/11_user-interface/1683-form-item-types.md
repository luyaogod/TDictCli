# Form item types

> The form item types defines the purpose of form elements.


## Child topics

- [BUTTON item type](1684-button-item-type.md): Defines a push-button that can trigger an action.
- [BUTTONEDIT item type](1685-buttonedit-item-type.md): Defines a line-edit with a push-button that can trigger an action.
- [CHECKBOX item type](1686-checkbox-item-type.md): Defines a boolean or three-state checkbox field.
- [COMBOBOX item type](1687-combobox-item-type.md): Defines a line-edit with a drop-down list of values.
- [DATEEDIT item type](1688-dateedit-item-type.md): Defines a line-edit with a calendar widget to pick a date.
- [DATETIMEEDIT item type](1689-datetimeedit-item-type.md): Defines a line-edit with a calendar widget to pick a datetime.
- [EDIT item type](1690-edit-item-type.md): Defines a simple line-edit field.
- [FOLDER item type](1691-folder-item-type.md): Defines a layout area to hold folder pages.
- [GRID item type](1692-grid-item-type.md): Defines a layout area based on a grid of cells.
- [GROUP item type](1693-group-item-type.md): Defines a layout area to group other layout elements together.
- [HBOX item type](1694-hbox-item-type.md): Defines a layout area to render child elements in horizontal direction.
- [IMAGE item type](1695-image-item-type.md): Defines an area that can display an image resource.
- [LABEL item type](1696-label-item-type.md): Defines a simple text area to display a read-only value.
- [PAGE item type](1697-page-item-type.md): Defines the content of a folder page.
- [PROGRESSBAR item type](1698-progressbar-item-type.md): Defines a progress indicator field.
- [RADIOGROUP item type](1699-radiogroup-item-type.md): Defines a mutual exclusive set of options field.
- [SCROLLGRID item type](1700-scrollgrid-item-type.md): Defines a scrollable grid view widget.
- [SLIDER item type](1701-slider-item-type.md): Defines a slider form item.
- [SPINEDIT item type](1702-spinedit-item-type.md): Defines a spin box widget to enter integer values.
- [TABLE item type](1703-table-item-type.md): Defines a list view widget.
- [TEXTEDIT item type](1704-textedit-item-type.md): Defines a multi-line edit field.
- [TIMEEDIT item type](1705-timeedit-item-type.md): Defines a line-edit field with a clock widget to pick a time.
- [TREE item type](1706-tree-item-type.md): Defines a tree view widget.
- [VBOX item type](1707-vbox-item-type.md): Defines a layout area to render child elements in vertical direction.
- [WEBCOMPONENT item type](1708-webcomponent-item-type.md): Defines a specialized form item that holds an external component.
