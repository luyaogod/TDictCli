# Understanding action defaults files

> This is an introduction to action default files.

Action defaults files define the defaults for action attributes in an XML file.
These defaults can be overwritten with form item attributes, or with dialog action
handler attributes, when using default action views.

This section describes only the .4ad action defaults file
reference, for more details see [Configuring actions](2259-configuring-actions.md "Action attributes related to decoration, keyboard shortcuts, and behavior can be defined with action attributes.").
