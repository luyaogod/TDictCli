# Supported scrollgrid features (mobile)

> The list view provides features that are supported on mobile devices.

The list view features supported on mobile devices include:

- [Finding rows matching a pattern](2325-finding-rows-matching-a-pattern.md "List controllers implement a built-in find. This feature can be disabled if not required.")

  Since mobile devices have no physical
  keyboard, you can't hit CTRL-F to fired the "find" action. The default action view for the "find"
  action is not visible by default, but it can be shown with the `DEFAULTVIEW=YES`
  action default attribute, to make the "find" feature available on mobile devices.
- [List reduce filter](2327-list-reduce-filter.md "The reduce filter allows a user to limit the row set in the list by using a filter.")
