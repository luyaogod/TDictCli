# Table features not supported on mobile

> Some table / list view features are not supported on mobile devices.

The list view features not supported on mobile devices include:

- [Multiple row selection](2314-multiple-row-selection.md "Multiple row selection allows the end user to select several rows within a list of records.")
- [Keyboard seek to matching row](2326-keyboard-seek-to-matching-row.md "The keyboard seek feature allows a user to find a row in a read-only list, by typing characters.")
- [Drag & drop](2370-drag-drop.md "Explains programming techniques for the drag & drop feature.")

Note also that there are no column headers/titles in mobile list views.
