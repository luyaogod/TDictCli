# CLEAR SCREEN

> Clears the complete application screen.

## Syntax

```
CLEAR SCREEN
```

## Usage

The `CLEAR SCREEN` instruction is typically used in TUI mode to clear the complete
screen and make the root screen window the current window on the stack.

The whole screen will be cleared, including prompt, error and message lines (the menu
line is not cleared).
