# Keyboard accelerator names

> Reference for keyboard accelerator names to be used in ACCELERATOR* attributes, and in ON KEY / COMMAND KEY clauses in source dialog code.


## Child topics

- [ON KEY Virtual keys](2293-on-key-virtual-keys.md): Virtual keys are the key names that can be used in program instructions such as ON KEY and COMMAND KEY.
- [Accelerator key names](2294-accelerator-key-names.md): Accelerators keys are attributes defining the keyboard shortcuts for actions.
- [Accelerator key modifiers](2295-accelerator-key-modifiers.md): Key modifiers define keyboard control key combinations in accelerator key names.
