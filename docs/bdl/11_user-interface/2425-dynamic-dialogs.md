# Dynamic Dialogs

> Dialogs can be created at runtime with the ui.Dialog class.


## Child topics

- [Understanding dynamic dialogs](2426-understanding-dynamic-dialogs.md): This section provides basics about dynamic dialogs.
- [Create forms dynamically](2427-create-forms-dynamically.md): Dynamic dialogs are typically used with forms that are generated at runtime.
- [Instantiate a dynamic dialog](2428-instantiate-a-dynamic-dialog.md): The dynamic dialogs needs to be created with specific ui.Dialog methods.
- [Configuring a dynamic dialog](2429-configuring-a-dynamic-dialog.md): The dynamic dialogs can be configured with attributes.
- [The dynamic dialog event loop](2430-the-dynamic-dialog-event-loop.md): Dynamic dialog body is implemented with a WHILE loop using ui.Dialog.nextEvent().
- [Controlling field values](2431-controlling-field-values.md): Fields values in dynamic dialogs can be manipulated dynamically.
- [Ending dynamic dialogs](2432-ending-dynamic-dialogs.md): Describes how to terminate dynamic dialogs.
- [Dynamic multiple dialog](2433-dynamic-multiple-dialog.md): Dynamic dialogs allows you to create the equivalent of a DIALOG procedural dialog.
- [Using dynamic cursors](2434-using-dynamic-cursors.md): Implementing a dynamic dialog based on the database schema.
- [DISPLAY ARRAY dynamic dialog](2435-display-array-dynamic-dialog.md): DISPLAY ARRAY can be implemented with dynamic dialogs.
- [Paged mode DISPLAY ARRAY](2436-paged-mode-display-array.md): Dynamic dialogs using DISPLAY ARRAY can use ON FILL BUFFER events to fill pages of rows.
- [Additional features](2437-additional-features.md): Miscellaneous features of dynamic dialogs.
