# AUTOSCALE attribute

> The AUTOSCALE attribute causes the form element contents to automatically scale to the size given to the item.

## Syntax

```
AUTOSCALE
```

## Usage

For images, this attribute forces the image to be stretched to fit in the area reserved for the
image.

See [Controlling the image layout](1585-controlling-the-image-layout.md "Explains how image form items can be sized in different front-end layout systems.") for more details.
