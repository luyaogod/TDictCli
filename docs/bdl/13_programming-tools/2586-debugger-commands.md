# Debugger commands

> This topic lists all debugger commands.


## Child topics

- [backtrace / where](2587-backtrace-where.md): The backtrace commands prints a summary of how your program reached the current state.
- [break](2588-break.md): The break command defines a break point to stop the program execution at a given line or function.
- [call](2589-call.md): The call command calls a function in the program.
- [clear](2590-clear.md): The clear command clears the breakpoint at a specified line or function.
- [continue](2591-continue.md): The continue command continues the execution of the program after a breakpoint.
- [delete](2592-delete.md): The delete command allows you to remove breakpoints that you have specified in your debugger session.
- [detach](2593-detach.md): The detach command closes the TCP connection of a remove debug session.
- [disable](2594-disable.md): The disable command disables the specified breakpoint.
- [display](2595-display.md): The display command displays the specified expression's value each time program execution stops.
- [down](2596-down.md): The down command moves down in the call stack.
- [echo](2597-echo.md): The echo command prints the specified text as prompt.
- [enable](2598-enable.md): The enable command enables breakpoints that have previously been disabled.
- [finish](2599-finish.md): The finish command continues the execution of a program until the current function returns normally.
- [frame](2600-frame.md): The frame command selects and prints a stack frame.
- [help](2601-help.md): The help command provides information about debugger commands.
- [ignore](2602-ignore.md): The ignore command defines the number of times a breakpoint must be ignored.
- [info](2603-info.md): The info command describes the current state of your program.
- [list](2604-list.md): The list command prints source code lines of the program being executed.
- [next](2605-next.md): The next command continues running the program by executing the next source line in the current stack frame, and then stops.
- [output](2606-output.md): The output command prints only the value of the specified expression, suppressing any other output.
- [print](2607-print.md): The print command displays the current value of the specified expression.
- [ptype](2608-ptype.md): The ptype command prints the data type or structure of a variable.
- [quit](2609-quit.md): The quit command terminates the debugger session.
- [run](2610-run.md): The run command starts the program.
- [set](2611-set.md): The set command allows you to configure your debugger session and change program variable values.
- [source](2612-source.md): The source command executes a file of debugger commands.
- [signal](2613-signal.md): The signal command sends an interruption signal to the program.
- [step](2614-step.md): The step command continues running the program by executing the next line of source code, and then stops.
- [tbreak](2615-tbreak.md): The tbreak command sets a temporary breakpoint.
- [tty](2616-tty.md): The tty command resets the default program input and output for future run commands.
- [undisplay](2617-undisplay.md): The undisplay command cancels expressions to be displayed when the program execution stops.
- [until](2618-until.md): The until command continues running the program until the specified location is reached.
- [up](2619-up.md): The up command selects and prints the function that called this one, or the function specified by the frame number in the call stack.
- [watch](2620-watch.md): The watch command sets a watchpoint for an expression.
- [whatis](2621-whatis.md): The whatis command prints the data type of a variable.
