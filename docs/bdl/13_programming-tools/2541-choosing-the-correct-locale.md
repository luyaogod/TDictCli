# Choosing the correct locale

Before starting to edit source files, you must identify and configure the editor with the locale
(character set) you want to use in your sources.

The language supports single-byte and multibyte character sets. When developing multilingual
applications, we recommend that you write .per and .4gl
source files in ASCII, and externalize language-dependent messages in string resource files.
