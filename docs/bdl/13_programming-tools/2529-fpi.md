# fpi

> The fpi tool displays product version information.

## Syntax

```
fpi [options]
```

1. options are described in Table 1.

## Options

| Option | Description |
| --- | --- |
| `-V` | Displays version information for the Genero BDL package. |
| `-h` | Displays options for the tool. |
| `-l` or `--list` | List version information for all Genero BDL command line tools. |

## Usage

The fpi command line tool can be used to list version information
for all command line tools available in the Genero BDL package.
