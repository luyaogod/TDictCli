# Program profiler

> Find out what function is causing the bottleneck in your program.


## Child topics

- [Understanding the profiler](2623-understanding-the-profiler.md): The profiler is a tool built into the runtime system that allows you to know where your program spends processing time, and which function calls which function.
- [Syntax of the program profiler](2624-syntax-of-the-program-profiler.md): The program profiler is enabled by using the -p option of fglrun.
- [Profiler output: Flat profile](2625-profiler-output-flat-profile.md): The flat profile shows a summary of the functions called during the program execution.
- [Profiler output: Call graph](2626-profiler-output-call-graph.md): The profiler call graph provides detailed function call information.
- [Example](2627-example.md): Program profiler example.
