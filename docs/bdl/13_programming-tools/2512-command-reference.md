# Command reference

> Command line tools provided by FGLGWS packages.

This section contains reference topics of the FGLGWS command line tools.

## Child topics

- [fglrun](2513-fglrun.md): The fglrun tool is the runtime system program that executes p-code programs.
- [fglform](2514-fglform.md): The fglform tool compiles form specification files into XML formatted files used by programs.
- [fgl2p](2515-fgl2p.md): The fgl2p tool compiles source files and assembles p-code modules into a .42r program or a .42x library.
- [fglcomp](2516-fglcomp.md): The fglcomp tool compiles .4gl source files into .42m p-code modules, and does various other tasks.
- [fgllink](2517-fgllink.md): The fgllink tool assembles p-code modules produced with fglcomp into a .42r program or a .42x library.
- [fglmkmsg](2518-fglmkmsg.md): The fglmkmsg tool compiles .msg message files into a binary version used by programs.
- [fglmkext](2519-fglmkext.md): The fglmkext tool compiles and links a user C Extension.
- [fgldb](2520-fgldb.md): The fgldb tool is an interface program for remote debugging.
- [fgldbsch](2521-fgldbsch.md): The fgldbsch tool generates the database schema files from an existing database.
- [fglmkstr](2522-fglmkstr.md): The fglmkstr tool compiles .str localized string resource files.
- [fglwsdl](2523-fglwsdl.md): The fglwsdl tool produces web services stub files for client or server programs (from WSDL / XSD).
- [fglrestful](2524-fglrestful.md): The fglrestful tool produces REST web services stub files for client programs using an OpenAPI specification.
- [fglpass](2525-fglpass.md): The fglpass tool allows you to encrypt passwords.
- [fglgar](2526-fglgar.md): The fglgar is a tool for packaging applications for deployment on any web server with Genero Application Server (GAS).
- [fglgitformat](2527-fglgitformat.md): The fglgitformat tool reformats the source lines changed in a GIT history.
- [fglformatdiff](2528-fglformatdiff.md): The fglformatdiff tool reformats source lines of a unified diff text.
- [fpi](2529-fpi.md): The fpi tool displays product version information.
