# Mobile app execution modes

> Mobile apps can be fully embeeded as a standalone or can execute on a server and display forms on the mobile device.

On iOS and on Android™, standalone
Genero apps are installed and started on the device as other apps. In this configuration, the
application program files, the runtime system and the database are present on the mobile device.

When a permanent network connection is available (WIFI), it is also possible to have a
lightweight app installed on the device, that executes the real application code on a server,
displaying forms on the device. With this architecture, your mobile app benefits from the processing
power of the server, and can access a large database.

For more details, see [Starting programs on a mobile device](../09_advanced-features/0829-executing-programs.md).
