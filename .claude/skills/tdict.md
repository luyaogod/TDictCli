# TDict — ERP 数据字典查询

## 这是什么

TDict 带一份**ERP 数据字典与业务元数据**：系统中每张数据表是干什么的、每个字段的中文含义与类型、字段会被怎样校验、下拉选项从哪来、画面字段用什么控件、程序报错编号的文本是什么、某个系统参数是做什么的——用一条命令按**表名或编号**就能查到，不用翻代码、翻画面、问人。

本地已随工具带好数据（约 3,882 张表的字段定义、148,539 个字段，以及校验/分类码/开窗/消息/参数等元数据，合计约 85 万行）。数据更新方式见文末「数据维护」。所有输出默认简体中文。

## 能查什么（速查）

| 想查什么 | 命令 | 输入样子 |
|---|---|---|
| 数据表结构：表说明、字段含义/类型/主键、索引 | `tdict rt <表名>` | `dzea_t`、`oobd_t` |
| 字段校验规则（r.v）：校验 SQL、参数、条件、错误讯息 | `tdict rv [识别码]` | `v_ooba002_07`，或 `--kw 料号` 搜索 |
| 系统分类码（SCC）：下拉/选项的"值→说明" | `tdict scc [分类码]` | `4`，或 `--kw 币别` 搜索 |
| 字段画面规格：控件、下拉来源、格式、必填 | `tdict desc <表名> [字段]` | `oobd_t oobd002` |
| 可复用开窗（r.q）：开窗选单查什么、回传什么 | `tdict rq [开窗码]` | `q_apca001` |
| 系统消息：报错/提示编号的文本与处理建议 | `tdict msg <编号>` | `std-00006`、`azz-00041` |
| 系统参数说明（系统/企业/据点级） | `tdict sysp <编号>` | `A-SYS-0040`、`E-CIR-0001` |
| 单据参数说明（单据别 + 适用单据） | `tdict docp <编号>` | `D-MFG-0076` |

**始终优先用 TDict 而不是去翻 CSV/源码文件**：查到的说明自带中文翻译与字段语义，快且全。

## 命令详解

### `tdict rt <表名>` — 数据表字典

**这是什么数据**：系统数据表的登记档案。每张表在系统里做什么（表说明/模块/类型）、有哪些字段（字段名、中文含义、数据类型、长度、主键、必填）、主键/外键、索引。读代码、看 SQL、查界面字段含义时用它。

**示例输入**：表名（支持逗号查多张）：`dzea_t`（表登记档）、`oobd_t`、`dzeb_t`。

**输出长这样**：

```
$ tdict rt dzea_t
=== dzea_t ===
表说明: 数据表主档
模块: ADZ    类型: X

字段 (31):
序号  字段名        字段说明       数据类型       长度  主键  必填  备注
--  ---------  ----------  ---------  ---  --  --  --
1   dzeastus   状态码       varchar2   10
2   dzea001    table编号   varchar2   15   PK  Y
...

键值 (1):
键名       类型  键值字段   外键表  外键字段
dzea_pk  主键  dzea001

索引 (1):
索引名      类型  索引字段
dzea_pk  U   dzea001
```

输出里的取值说明：**类型**列见文末「类型码」；主键显示 `PK`；必填 `Y`。`--json` 输出结构化对象，`--csv` 平铺字段明细（含表名列）。

### `tdict rv [识别码]` — 字段校验带值 (r.v)

**这是什么数据**：字段校验规则库。系统保存数据前做的各种检查（"该字段必须存在/自动带出/两者都要"）是**可复用的校验模板**：每条校验有一个识别码，含一段校验 SQL（SQL 里用 `<field>`、`arg1~9`、`:TODAY` 等占位符，运行时代入实际字段与参数）、外部参数定义与判断条件。想知道某字段被怎样校验、校验不过显示什么错误讯息，或要给字段绑校验时用。

**示例输入**：识别码（形如 `v_表名_用途`，如 `v_ooba002_07`）；不带参数列出全部（`--kw 料号` 按识别码/说明过滤）。

**输出含什么**：列表=识别码/客制（标准/客制）/说明/型态/错误讯息/备注。详情=单头 + SQL 指令 + 参数 + 判断条件：

- **型态**：1=检查存在 / 2=带值 / 3=检查存在并带值
- **SQL 指令**：校验 SQL 原文，末尾附图例说明占位符含义（`<field>` 回传字段、`arg1~9` 外部参数、`:TODAY` 当前日期、`:DEPT` 等全局变量）
- **参数**：顺序、参数名称（对应 `arg1~9`）、日期型态（1=年月日 / 2=年月日时分秒 / 3=毫秒 / 其他=字符串）、说明
- **判断条件**：顺序、条件 SQL、条件成立时显示的错误讯息

### `tdict scc [分类码]` — 系统分类码 (SCC)

**这是什么数据**：系统里各种下拉/选项的"选项字典"——币别、单据类型、料件属性、各种分类，统一按分类码组织：一个分类码 = 一组「值 → 说明」，画面上看到的下拉选项就是它。写代码灌下拉、查某字段可选项、按分类码查说明时用。

**示例输入**：分类码（多为数字，如 `4`、`241`）；不带参数列出全部（`--kw 币别` 按分类码/名称过滤）。

**输出含什么**：列表=分类码/群组/状态（启用/停用）/名称/值数。详情=单头（群组、状态、名称、说明）+ **分类值表**（值、说明、排序、标准/客制）——说明列就是下拉里显示的文字。部分分类码的值还带**扩展数据列**（输出中列为 `gzcb003`~`gzcb015`，仅显示非空）：这些列的用途由各分类码自己定义（如某分类码用扩展列存群组编号区间、另一个存格式），结合该分类码的语境理解。

### `tdict desc <表名> [字段名]` — 字段画面规格

**这是什么数据**：字段在画面上的"设计规格"：每个字段用什么控件（输入框/下拉/日期…）、下拉取哪个分类码（SCC）、显示格式与宽度、必填与否、默认值、开窗程序、最大/最小值、串查程序等——画面设计器按它生成画面，运行期查询界面也按它给下拉灌选项。要复刻/理解某个画面的字段行为时用。

**示例输入**：`tdict desc oobd_t`（整表）；`tdict desc oobd_t oobd002`（单字段完整规格）。

**输出含什么**（语义说明）：

| 输出项 | 含义 |
|---|---|
| 控件 | 字段在画面的控件类型：03=ComboBox（下拉）、05=Edit（输入）、09=RadioGroup、01=ButtonEdit（带开窗按钮）、04=DateEdit、11=SpinEdit、12=TextEdit 等 |
| SCC码 | 下拉/单选控件的选项来源=哪个系统分类码（用 `tdict scc <码>` 查可选项） |
| 必填 | Y/N |
| 显示宽度 | 控件宽度（"整数,小数"） |
| 格式 | 显示格式 |
| 默认值 / 最大/最小值 | 默认值与取值范围（含比较符号） |
| 编辑开窗 / 查询开窗 | 字段上点按钮弹出的程序 |
| 校验带值 | 该字段绑定的校验识别码（用 `tdict rv <码>` 查校验内容） |
| 串查 | 串查/参考程序 |
| 大小写 | U/L |
| 客制识别 | 标准/客制 |

### `tdict rq [开窗码]` — 可复用开窗 (r.q)

**这是什么数据**：可复用开窗——代码里 `CALL q_xxx()` 弹出的"查寻选单"定义：每条开窗 = 一段带占位符的 SQL（选取字段/表/条件用 `<field>/<table>/<wc>` 标记）+ 外部参数（对应 `arg1~9`）+ 显现列与回传设置。读代码遇到开窗调用、想知道它查什么表、回传哪些值时用。

**示例输入**：开窗码（`q_` 开头，如 `q_apca001`）；不带参数列出全部（`--kw 料号` 过滤）。

**输出含什么**：单头（状态、SQL 指令原文+占位符图例、每页笔数、HardCode（Y=跳过自动产生）、行业别、说明）+ 参数（顺序/名称/日期型态，同 rv 译码）+ 显现设定（显现顺序、字段、显示控件、是否回传——回传 `Y` 的字段按显现顺序构成调用方收到的 `return1~9`）。

### `tdict msg <编号>` — 系统消息

**这是什么数据**：系统所有提示/报错消息的记录。程序报错、日志里出现的编号（如 `std-00006`）都可以查到它的完整文本、建议处理方式与给维护人员的技术细节——看到报错编号先查它，能直接拿到"怎么处理"。

**示例输入**：消息编号——格式为 `std-00001`、`azz-00041`、`lib-xxxxx`（类型-流水）或负整数（SQLCODE，如 `-263`）。负整数编号需写成 `tdict msg -- -263`。

**输出长这样**：

```
=== std-00006 (zh_CN) ===
类型:     错误 (1)
状态:     启用
文本:     输入的资料已存在
建议处理: 请重新审核您所需要输入的资料
```

输出含：**文本**（报错原文）、**建议处理**、**建议作业**（可执行哪个作业处理，附作业名称）、**技术细节**（给程式人员的详细讯息）、**类型**（0=警告 / 1=错误 / 2=资讯）、**状态**（启用/停用）。消息按语言各一条：默认显示 `zh_CN`，`--lang zh_TW` 换语言；该编号没有指定语言时会列出可用语言。

### `tdict sysp <编号>` / `tdict docp <编号>` — 参数说明

**这是什么数据**：系统参数与单据参数——决定系统行为/单据流程的可配置项。参数有编号、名称与中文说明（说明"这个参数是干什么的、怎么填"），并定义可填的**型态、值域与预设值**。

- `tdict sysp`：**系统/企业/据点级参数**。编号格式 = 型态码 + 领域 + 4 位流水，如 `A-SYS-0040`（A=系统级）、`E-CIR-0001`（E=企业级）、`S-BAS-0028`（S=据点级）
- `tdict docp`：**单据别参数**（编号 `D-` 开头，如 `D-MFG-0076`），并附它适用哪些单据性质（模块 + 单据性质清单）

**输出长这样**：

```
=== A-SYS-0040 (zh_CN) ===
名称:     系统是否允许LIB相关资源被签出
说明:     系统是否允许LIB相关资源被签出
群:       gzsa_t  系统级参数(系统全域参数)
型态:     Y/N (1)
领域:     SYS
预设值:   N
异常处理: 改抓设定时的预设值 (1)
状态:     启用
```

输出含：名称/说明（多语言）、参数群与级别、**型态**（1=Y/N 2=整数选项 3=范围设定 4=字符或SCC 5=日期）、领域、预设值、值域、SCC 选项、校核/开窗引用、取参异常处理、状态与长备注。`tdict docp` 额外输出**单据性质绑定**表（该参数作用在哪些单据性质上）。

> 注：这里查的是参数的"定义与说明"；每个环境下参数**实际设的值**不在本命令范围（实际值在各环境的参数值维护画面/作业里看）。

## 数据维护（本地数据怎么更新）

查询读的是本地数据。出现以下情况时更新一次：

- 数据较旧（如刚加的新表/新消息编号查不到）→ `tdict db sync`（从 ERP 刷新，全量约 85 万行、2 分钟级；`--conn <环境名>` 指定从哪个环境刷）
- 不想要本地数据、直接查某环境服务器 → 命令加 `--conn <环境名>`（如 `tdict msg aoo-00120 --conn 主机正式区`，需网络）

## 全局参数

| 参数 | 说明 |
|---|---|
| `--json` | 输出缩进 JSON（机器可读） |
| `--csv` | 输出 CSV（仅列表类命令） |
| `--lang <语言>` | 说明语言（rv/scc/desc/rq/msg/sysp/docp，默认 zh_CN） |
| `--kw <关键字>` | 按识别码/名称过滤（列表类命令） |
| `--conn <环境名>` | 直接查该环境（远程），如 `主机正式区`、`恒烁正式区` |
| `-d <路径>` | 本地数据库路径（默认 erp_data.db） |
| `--config <路径>` | 配置文件路径（默认 config.json） |

## BDL 语言参考文档

数据字典回答"这张表/字段/校验/消息是什么";**语言语法问题**(BDL 语句、内置函数、
fgldb 调试器命令等)查项目内 BDL 语言参考文档:

```bash
tdict bdldoc dir    # 输出文档目录(第一行即路径;未设置则先执行 tdict bdldoc dir <目录>)
```

默认在仓库 `docs/bdl/`(Genero BDL 官方文档 markdown,无图片,约 5,200 篇):
`08_language-basics`/`09_advanced-features`(语言基础/进阶)、`10_sql-support`(SQL 支持)、
`15_library-reference`(内置函数/库)、`13_programming-tools`(fgldb 等工具)。读 .4gl 代码、
解释语法结构、调试器命令不确定时,先在该目录检索再回答。

`tdict rt` 输出的 **表类型**（每张表在系统里的角色）：

| 码 | 含义 |
|---|---|
| B | 基础数据 (Basic) |
| M | 主档 (Master) |
| T | 交易单头 (Transaction header) |
| D | 交易单身/明细 (Detail) |
| L | 多语言 (Language) |
| V | 提速档/视图 (View) |
| X | 系统/交叉 (Cross-reference) |
| H | 历史/暂存 (History/Temp) |

| 码 | 含义 |
|---|---|

| C003, C004, C105 | 字符 (varchar2) |
| D001 | 日期 (date) |
| Z012 | 时间戳 (timestamp) |
| Z501 | 一般 flag (Y/N) |
| Z509 / Z510 | 短说明 / 长说明 |
| Z521 / Z522 | 文件编号引用 / 字段编号引用 |
| Z504 / Z505 | 人员编号 / 组织编号 |
