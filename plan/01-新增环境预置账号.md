# 01 - 新增环境时预置数据库账号(ds / dsdata / dsdemo)

## Context

`tdict serve` 的「环境配置」视图里，左侧「新增环境」会创建一个空环境，第二个页签「数据库」的账号列表是空的。实际上每个 T100 环境挂的库上都固定用三个标准 schema 账号（账号=密码）：`ds`、`dsdata`、`dsdemo` —— 现有 `config.json` 的三个环境里都手工维护着这三条（顺序各不相同）。

于是每建一个新环境都要在「数据库」页签手工敲三遍账号密码。本次改动让**新增环境时自动预置这三条账号**，用户仍可随意增删改。

非目标：不动已存在的环境（加载回来的环境保持其账号列表原样，不做迁移）；不改后端、不改 `config.json` 结构。

## 改动

只改一个文件：`web/src/SettingsView.tsx`。

### 1. 预置常量(`web/src/SettingsView.tsx:16` 附近)

`blankDb()` 原来 `accounts: []`。改成预置三条，并抽成具名常量说明来历：

```tsx
// T100 标准 schema 账号(密码=账号):新增环境时预置,可自由增删改
const DEFAULT_ACCOUNTS: DBAcct[] = [
  { account: 'ds', password: 'ds' },
  { account: 'dsdata', password: 'dsdata' },
  { account: 'dsdemo', password: 'dsdemo' },
]

const blankDb = (): DBConnection => ({
  type: 'oracle', host: '', port: 1521, service: '', database: '',
  accounts: DEFAULT_ACCOUNTS.map((a) => ({ ...a })), // 复制,避免各环境共享同一数组
})
```

`DBAcct` 已在 `web/src/api.ts:2` 导出，在 `web/src/SettingsView.tsx:11` 的 import 里补上 `type DBAcct`。

顺序按 `ds` / `dsdata` / `dsdemo`。注意影响：客户端直连（数据库页签「测试连接」、`tdict db ping`、`db sync`）取**账号列表首项**，所以新环境的直连账号将是 `ds`。

### 2. 覆盖到的路径(无需额外改动，走 `blankDb()` 即自动生效)

- `addSsh()`（`SettingsView.tsx:132`）→ `blankSsh()`（`:17`，内部 `{ ...blankDb() }`）→ 新环境自带三条账号，切到「数据库」页签立即可见，点「保存」写入 `config.json`。
- 「添加数据库」空状态按钮（`:346` 的 `patchDb(sel, {})` → `blankDb()` 兜底分支，仅当环境完全没有 `db` 块时出现）也会预置，行为一致。
- `load()`（`:46`）不动：已有环境按 `config.json` 原样加载，账号列表不被覆盖。

`saveAll()`（`:71`）的账号序列化逻辑无需改：它已按 `{account, password}` 原样落盘，只过滤空账号名。

## 文档

`README.md:414` 的「数据库」表格行补一句：新增环境时账号列表默认预置 `ds` / `dsdata` / `dsdemo`（密码=账号），可自行增删。

## 验证

1. 构建前端与二进制（`web/dist` 被 `go:embed` 打进二进制，且 `.gitignore` 忽略，必须重新构建才能看到效果）：
   - `cd web && npm run build`（含 `tsc --noEmit` 类型检查）
   - `go build -o tdict.exe .`
2. `./tdict.exe serve`，浏览器打开页面 → 「环境配置」→ 点「新增环境」→ 切到「数据库」页签：应已列出 `ds` / `dsdata` / `dsdemo` 三行、密码均为同名账号。
3. 填好 SSH 主机等后点「保存」，检查 `config.json` 中新环境的 `db.accounts` 确实是这三条且顺序为 ds → dsdata → dsdemo。
4. 回归：切换到已有环境（如 `t35prd`），数据库页签的账号列表应与改动前完全一致（顺序、内容都不变）。
5. 顺手验证「添加数据库」空状态路径：编辑 `config.json` 手工删掉某环境的 `db` 块后刷新页面，点「添加数据库」，同样应带出三条预置账号。
